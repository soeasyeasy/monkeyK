# 去掉所有教程小节标题的章节号前缀

## 方案

将所有教程 markdown 文件中的二级标题 `## X.Y 标题` 改为 `## Y 标题`，去掉章节号前缀。

- `## 2.1 为什么需要数据类型？` → `## 1 为什么需要数据类型？`
- `## 17.3 String 常用方法` → `## 3 String 常用方法`

章节编号由侧边栏 `tutorial-series.ts` 的 `chapter.number` 控制，markdown 内不再重复。

## 修改范围

所有 `src/content/tutorials/` 下的 `.md` 文件，正则替换：
- 匹配：`^## \d+\.` → 替换为：`## `
- 只改二级标题，不动一级标题、三级标题、正文

## 不修改

- 一级标题 `# 第X章：xxx`
- 三级标题 `### X.Y.Z`
- 正文中的引用（如"见 2.1 节"）
- `tutorial-series.ts`
- 文件名

## 验证

修改后 grep 确认没有 `## \d+\.` 格式，只有 `## \d+ ` 格式。
