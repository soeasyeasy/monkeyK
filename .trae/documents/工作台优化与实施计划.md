# AI 个人工作台 - 实施计划

## 一、现状分析

### 1.1 当前项目架构
- **技术栈**: Vue 3 + TypeScript + Vite + Vue Router + Pinia
- **设计风格**: Apple 风格毛玻璃设计，支持多主题切换（浅色/深色 + 6种强调色）
- **现有工作台**: 仅有基础待办事项功能（`/todo` 路由，`TodoIndex.vue`）
  - 支持：添加/编辑/删除待办、优先级、标签、截止日期、筛选
  - 数据：localStorage 持久化
  - 缺失：无模块化仪表盘、无其他功能模块、无 AI 能力

### 1.2 目标
将现有简单待办页面改造为需求文档中的 **AI 个人工作台**：
- 模块化仪表盘（待办、记账、打卡、目标）
- 设置页面（AI API/Key 配置）
- AI 能力层（智能建议、自然语言操作、数据洞察、AI 助手对话、报告生成）

## 二、功能范围

### 2.1 核心模块
| 功能 | 说明 | 实现方式 |
|------|------|----------|
| **模块化仪表盘** | 多卡片布局，展示不同模块数据 | Vue 组件 + CSS Grid |
| **待办模块** | 已有，优化为卡片形式 | 复用现有 TodoIndex 逻辑 |
| **习惯打卡模块** | 自定义习惯、打卡记录、连续天数 | localStorage + 日历组件 |
| **记账模块** | 快速记账、分类统计、月度预算 | localStorage + 饼图 |
| **目标/OKR 模块** | 目标设定、进度追踪、倒计时 | localStorage + 进度条 |
| **卡片拖拽排序** | 调整模块位置 | vuedraggable |
| **设置页面** | AI API 配置、用户偏好 | 新页面 + localStorage |
| **AI 助手浮窗** | 随时对话，操作工作台 | SSE 流式对话 |
| **AI 智能建议** | 基于数据给出可执行建议 | 调用 AI API |
| **AI 自然语言操作** | 对话式操作工作台 | AI 解析意图 → 执行 |
| **AI 数据洞察** | 跨模块关联分析 | AI 分析多模块数据 |
| **AI 报告生成** | 周报/月报自动生成 | AI 汇总数据生成文本 |
| **主题适配** | 所有模块支持现有主题系统 | CSS 变量 |
| **数据导出** | 导出 JSON 备份 | 前端下载 |

## 三、实施计划

### 3.1 技术选型
- **拖拽库**: `vuedraggable` (基于 Sortable.js，Vue 3 支持好)
- **HTTP 请求**: 原生 `fetch`（AI API 调用，支持 SSE 流式）
- **数据存储**: localStorage（按模块分 key）
- **状态管理**: Pinia（AI 配置和全局状态）

```
src/
├── views/
│   ├── Workspace.vue              # 新工作台主页面（替代 TodoIndex）
│   └── Settings.vue               # 设置页面（AI 配置）
├── components/
│   └── workspace/
│       ├── Dashboard.vue          # 仪表盘容器

│       ├── QuickActions.vue       # 快速操作区

│       └── AiAssistant.vue        # AI 助手浮窗（对话界面）

### 3.3 实施步骤

#### 阶段 1: 基础架构
1. 安装依赖：`vuedraggable`
2. 创建类型定义 `types/workspace.ts`

4. 创建 Pinia store：`stores/settings.ts`（AI API/Key 配置）
5. 创建 composables：

   - `useHabits.ts` - 习惯打卡
   - `useAccounting.ts` - 记账
   - `useGoals.ts` - 目标管理
   - `useAi.ts` - AI 能力封装

#### 阶段 2: 设置页面
1. 创建 `Settings.vue` - 设置页面
   - AI API 配置区（API 地址、API Key、模型选择）
   - 连接测试按钮
   - 用户偏好设置（昵称等）
   - 数据管理（导入/导出/清除）
2. 添加路由 `/settings`
3. AppHeader 导航增加设置入口

#### 阶段 3: 核心组件
1. `ModuleCard.vue` - 通用卡片包装器
2. `Dashboard.vue` - 仪表盘布局（Grid + 拖拽）

5. `AccountingModule.vue` - 记账（快速记账 + 统计 + 饼图）

#### 阶段 4: AI 能力

   - 数据洞察分析

   - 对话界面（气泡消息）

   - 建议展示区

#### 阶段 5: 主页面与整合

2. `QuickActions.vue` - 快速操作区

    ├── 导入数据
    └── 清除所有数据
```

#### AI 服务封装（useAi.ts）
```typescript
// 核心方法
interface UseAi {
  // 对话（流式）
  chat(messages: Message[], onChunk: (text: string) => void): Promise<void>
  // 获取智能建议
  getSuggestions(moduleData: ModuleData): Promise<string>
  // 解析自然语言指令
  parseIntent(text: string): Promise<AiIntent>
  // 生成报告
  generateReport(type: 'weekly' | 'monthly'): Promise<string>
  // 数据洞察
  getInsights(): Promise<string>
  // 检查是否已配置
  isConfigured: ComputedRef<boolean>
}

// AI 意图类型
interface AiIntent {
  action: 'add_todo' | 'add_expense' | 'check_habit' | 'set_goal' | 'query' | 'chat'
  params: Record<string, any>
}
```

## 四、风险与应对

| 风险 | 应对方案 |
|------|----------|
| AI API Key 安全性 | 仅存 localStorage，提示用户风险；不上传服务器 |
| AI API 跨域问题 | 使用 CORS 代理或提示用户配置 API 端点支持跨域 |
| 拖拽库兼容性 | 备选方案：使用原生 HTML5 DnD API |
| localStorage 容量限制 | 提示用户定期导出备份，限制历史记录数量 |
| 移动端拖拽体验差 | 移动端禁用拖拽，改为固定布局 |
