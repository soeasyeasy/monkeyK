# 教程中心布局优化

## 问题分析

当前布局存在以下空间浪费问题：

1. **主内容区过窄**：`max-width: 900px`，两侧各有 260px/220px 的边距（侧边栏和目录栏），实际可用宽度仅约 900px
2. **卡片单列展示**：每个分类下的教程卡片垂直排列，一行只显示一个，大量横向空间被浪费
3. **头部区域过大**：header 区域 padding 2rem，标题+副标题+分类标签占据过多纵向空间
4. **分类组间距过大**：`margin-bottom: 2.5rem`，分类之间空白过多
5. **卡片内边距偏大**：`padding: 1.25rem 1.5rem`，单行文字信息密度低

## 修改方案

### 1. TutorialIndex.vue - 卡片改为网格布局

**文件**: `src/views/TutorialIndex.vue`

- `.series-list` 从 `flex-direction: column` 改为 `display: grid; grid-template-columns: repeat(auto-fill, minmax(320px, 1fr)); gap: 1.25rem`
- 卡片从单列垂直列表变为多列网格，充分利用横向空间
- 减小 `.tutorial-index` 的 `max-width` 从 900px 改为 1200px，扩大内容区域
- 减小 `.index-header` 的 `padding` 从 `2rem` 改为 `1.5rem`，`margin-bottom` 从 `3rem` 改为 `2rem`
- 减小 `.category-group` 的 `margin-bottom` 从 `2.5rem` 改为 `1.75rem`
- 卡片 `.series-link` 的 `padding` 从 `1.25rem 1.5rem` 改为 `1rem 1.25rem`
- 卡片描述文字 `p` 限制为单行省略（`overflow: hidden; text-overflow: ellipsis; white-space: nowrap`），保持卡片高度一致

### 2. TutorialLayout.vue - 优化主内容区边距

**文件**: `src/layouts/TutorialLayout.vue`

- `.doc-main` 的 `margin-right` 从 `220px` 改为 `0`（教程中心页不需要右侧目录栏，TableOfContents 组件在没有 tocItems 时不会渲染）
- 确认右侧空间被释放给主内容区使用

## 涉及文件

| 文件 | 修改内容 |
|------|---------|
| `src/views/TutorialIndex.vue` | 卡片网格布局、间距优化、文字省略 |
| `src/layouts/TutorialLayout.vue` | 移除右侧边距 |

## 验证

- 运行 `npm run dev` 查看效果
- 确认卡片在宽屏下显示为 2-3 列网格
- 确认分类筛选功能正常
- 确认响应式布局在小屏幕下自动变为单列
