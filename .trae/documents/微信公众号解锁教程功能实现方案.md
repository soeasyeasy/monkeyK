# 微信公众号解锁教程功能实现方案

## 一、需求概述

实现纯前端的微信公众号解锁教程功能，用户需要关注公众号并输入密码才能查看被锁定的教程内容。密码加密存储在前端。

## 二、核心功能

### 2.1 功能特性
- 部分教程章节标记为"需要解锁"
- 未解锁时显示锁定遮罩层和提示信息
- 提供微信公众号二维码展示
- 需要输入正确的密码才能解锁
- 密码加密存储在前端（使用 Base64 + 混淆）
- 解锁后永久可访问（使用 localStorage 存储）

### 2.2 用户体验流程
1. 用户访问被锁定的教程章节
2. 页面显示锁定遮罩层，提示"需要关注公众号解锁"
3. 用户点击"立即解锁"按钮
4. 弹出微信公众号二维码和密码输入框
5. 用户关注公众号后输入密码
6. 密码正确则解锁，刷新页面显示完整内容

#### 3.1.2 密码加密工具
创建 `src/utils/password.ts` 管理密码加密和验证：

```typescript
// 加密后的密码（Base64 编码 + 简单混淆）
const ENCRYPTED_PASSWORD = 'MTIzMzIx'

// 混淆盐值（用于增加破解难度）
const SALT = 'monkeyk_salt_2024'

/**
 * 验证用户输入的密码是否正确
 * @param input 用户输入的密码
 * @returns 是否匹配
 */
export function verifyPassword(input: string): boolean {
  if (!input || input.trim() === '') return false
  
  // 解密过程：Base64 解码 + 反转
  try {
    const decoded = atob(ENCRYPTED_PASSWORD)
    const reversed = decoded.split('').reverse().join('')
    const actualPassword = reversed
    
    return input === actualPassword
  } catch (error) {
    console.error('密码验证失败:', error)
    return false
  }
}

/**
 * 生成加密密码（开发时使用）
 * @param password 原始密码
 * @returns 加密后的字符串
 */
export function encryptPassword(password: string): string {
  const reversed = password.split('').reverse().join('')
  return btoa(reversed)
}
```

### 3.1.3 解锁状态管理
创建 `src/utils/unlock.ts` 管理解锁状态：

```typescript
// 解锁状态键名
const UNLOCK_KEY = 'tutorial_unlocked'

// 检查是否已解锁
export function isUnlocked(): boolean {
  return localStorage.getItem(UNLOCK_KEY) === 'true'
}

// 设置解锁状态
export function setUnlocked(): void {
  localStorage.setItem(UNLOCK_KEY, 'true')
}

// 清除解锁状态（用于测试）
export function clearUnlock(): void {
  localStorage.removeItem(UNLOCK_KEY)
}

// 检查特定章节是否可访问
export function canAccessChapter(locked?: boolean): boolean {
  if (!locked) return true
  return isUnlocked()
}
```

### 3.3 页面集成

#### 3.3.1 修改 ChapterView.vue
在章节查看页面集成锁定逻辑：

```typescript
// 导入解锁工具
import { canAccessChapter, setUnlocked } from '../utils/unlock'
import { verifyPassword } from '../utils/password'
import LockOverlay from '../components/LockOverlay.vue'
import WechatModal from '../components/WechatModal.vue'

// 计算是否可访问
const canAccess = computed(() => {
  return canAccessChapter(chapter.value?.locked)
})

// 弹窗状态
const showModal = ref(false)

// 打开解锁弹窗
function openUnlock() {
  showModal.value = true
}

// 确认解锁（密码验证通过后调用）
function confirmUnlock() {
  setUnlocked()
  showModal.value = false
  // 重新加载内容
  loadMarkdown()
}
```

**模板修改：**
```vue
<template>
  <div class="chapter-view">
    <!-- 锁定遮罩层 -->
    <LockOverlay 
      v-if="!canAccess" 
      @unlock="openUnlock" 
    />
    
    <!-- 原有内容 -->
    <div v-else class="doc-content">
      <!-- ... 原有内容 ... -->
    </div>
    
    <!-- 微信弹窗（含密码输入） -->
    <WechatModal
      v-if="showModal"
      @confirm="confirmUnlock"
      @cancel="showModal = false"
    />
  </div>
</template>
```

```typescript
import { isUnlocked } from '../utils/unlock'
```

**模板修改：**
