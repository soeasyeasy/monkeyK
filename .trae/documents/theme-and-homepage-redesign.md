# 主题切换器优化与首页重设计

## 需求总结
1. 主题设置改成下拉选择器
2. 主题配色参考苹果设计风格
3. 重新设计项目首页（不使用 Vue 默认首页）

## 当前状态分析

### 主题切换器
- 当前实现：横向按钮组，5个主题并排显示
- 问题：占用空间大，不够简洁
- 文件：`src/components/ThemeSwitcher.vue`

### 主题配色
- 当前5个主题：浅色、深色、海洋、森林、紫罗兰
- 问题：配色不够精致，缺乏苹果风格的简洁感
- 文件：`src/assets/themes.css`

### 首页
- 当前实现：Vue 默认 HelloWorld 组件
- 文件：`src/App.vue`（非教程路由时显示）
- 问题：不是项目定制的首页

## 设计方案

### 1. 主题切换器改为下拉
**设计思路：**
- 使用单个按钮触发下拉菜单
- 按钮显示当前主题图标和名称
- 下拉菜单列出所有主题选项
- 选中状态用勾号或高亮显示
- 添加平滑的展开/收起动画

**实现要点：**
- 使用 `ref` 控制下拉菜单的显示/隐藏
- 点击外部区域关闭菜单
- 保持毛玻璃效果
- 响应式设计

### 2. 苹果风格主题配色
**精简主题：**
- 只保留 2 个主题：浅色（Light）和深色（Dark）
- 参考 Apple 官网的配色方案

**浅色主题（Light）：**
- 背景：纯白 `#FFFFFF` 或浅灰 `#F5F5F7`
- 文本：深灰 `#1D1D1F`
- 次要文本：中灰 `#86868B`
- 强调色：苹果蓝 `#007AFF`
- 边框：浅灰 `#D2D2D7`
- 卡片背景：白色带轻微阴影

**深色主题（Dark）：**
- 背景：深黑 `#000000` 或 `#1C1C1E`
- 文本：白色 `#F5F5F7`
- 次要文本：浅灰 `#86868B`
- 强调色：亮蓝 `#0A84FF`
- 边框：深灰 `#38383A`
- 卡片背景：深灰 `#1C1C1E` 带边框

**设计特点：**
- 大圆角（16px-20px）
- 精致的阴影（多层阴影）
- 微妙的模糊效果
- 简洁的配色方案
- 充足的留白

### 3. 新首页设计
**页面结构：**
1. **Hero 区域**
   - 大标题：TypeScript 从零到精通
   - 副标题：简短描述
   - CTA 按钮：开始学习
   - 背景：渐变或抽象图形

2. **特色展示**
   - 3-4 个特色卡片
   - 图标 + 标题 + 描述
   - 例如：12 章节、100+ 示例、可运行、从基础到实战

3. **章节预览**
   - 显示前 3 个章节
   - 每个章节卡片包含：编号、标题、描述
   - 查看更多按钮

4. **页脚**
   - 简单的版权信息
   - 相关链接

**设计风格：**
- 苹果风格的简洁设计
- 大字体、充足留白
- 卡片使用毛玻璃效果
- 渐变背景
- 流畅的悬停动画
