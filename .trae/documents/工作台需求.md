## 二、项目背景

### 2.1 市场背景

> "不需要懂代码、不用学复杂指令，用大白话就能让 AI 帮你搭建专属工作台。" —— 胡楚靓

- 2026年7月，95后创业者胡楚靓在抖音发布 AI 工作台教程，数日内引发全网"手搓 AI 工作台"热潮
- 用户用 AI 搭出了：**存钱记账、英语学习、育儿辅导、服装设计、健身打卡、考研规划**等五花八门的个人工作台
- 核心洞察：**普通人不想学 5 个 App，只想"说一句话"就拥有一个"懂我的管家"**

### 2.2 用户痛点

| # | 痛点 | 现状 |
|---|------|------|
| 1 | 工具碎片化 | 记账一个App、日程一个App、打卡一个App、笔记一个App，来回切换 |
| 2 | 数据不互通 | 各工具数据孤岛，无法联动分析（如：这个月花多了→自动压缩下周预算） |
| 3 | 缺乏个性化 | 通用App功能臃肿，80%功能用不上，想要的又没有 |
| 4 | 没有"主动性" | 传统工具被动等用户打开，不会主动提醒、建议、复盘 |
| 5 | 搭建门槛高 | 想用 Notion/飞书搭工作台，学习成本太高，劝退 |

### 2.3 产品目标

| 维度 | 指标 |
|------|------|
| 核心体验 | 用户用自然语言描述需求 → **3 分钟内**生成可用工作台 |
| 留存 | 7日留存 ≥ 45%，30日留存 ≥ 25% |
| 渗透 | 上线首月 DAU ≥ 10 万 |
| 满意度 | NPS ≥ 50 |
| 传播 | 用户自发分享率 ≥ 15%（对标抖音晒工作台热潮） |

## 五、核心功能详细说明

### 5.1 🧠 AI 搭建引擎（P0 · 核心卖点）

> 对标热点：用户说一句话，AI 直接生成整个工作台

| 项目 | 说明 |
|------|------|
| **入口** | 首次打开 → 对话框："用一句话描述你想要的工作台" |
| **输入示例** | "我是考研党，帮我做一个倒计时+每日学习计划+英语单词打卡+错题本的工作台" |
| **AI 处理** | ① 意图识别 → ② 拆解模块 → ③ 自动配置字段/规则 → ④ 生成仪表盘布局 |
| **输出** | 一个**可直接使用**的工作台（含 4-6 个模块卡片 + 预设数据 + 提醒规则） |
| **迭代** | 用户可继续对话："把记账模块加上""打卡改成每周5次""颜色换成莫兰迪色" |
| **耗时目标** | 从输入到可用 ≤ **60 秒** |

**模板市场（降低冷启动门槛）：**

| 模板分类 | 示例 |
|----------|------|
| 🎓 学习 | 考研倒计时工作台、雅思备考工作台、期末复习工作台 |
| 💰 理财 | 月薪存钱工作台、家庭账本工作台、副业收入追踪 |
| 🏃 自律 | 21天习惯养成、健身打卡工作台、早起挑战 |
| 👶 育儿 | 宝宝成长记录、辅食计划、疫苗接种提醒 |
| 💼 职场 | 周报自动生成、OKR追踪、项目看板 |
| 🎨 创作 | 自媒体选题库、灵感收集、发布日历 |

### 5.3 📦 内置模块库（详细说明）

#### ① 待办 / 日程模块

| 功能点 | 说明 |
|--------|------|
| 快速添加 | 输入"明天下午3点开会"→ AI 自动解析时间、创建日程 |
| 优先级 | P0/P1/P2 三级，支持 AI 自动排序 |
| 重复规则 | 每天/每周/自定义周期 |
| 提醒 | 推送 + 微信服务号 + 短信（可选） |
| 子任务 | 支持拆解为子步骤 |
| 联动 | 完成待办 → 自动更新打卡/目标进度 |

#### ② 记账 / 预算模块

| 功能点 | 说明 |
|--------|------|
| 快速记账 | 对话式："午饭花了32" → 自动归类"餐饮" |
| 拍照记账 | 拍小票 → OCR 识别 → 自动入账 |
| 预算管理 | 月/周预算设定，超支预警 |
| 分类统计 | 饼图/柱状图，按分类、时间维度 |
| AI 洞察 | "你本月奶茶花了¥287，比上月多40%，要不要设个上限？" |
| 存钱目标 | 设定目标金额 → 自动计算每日/每周需存金额 |

#### ③ 习惯打卡模块

| 功能点 | 说明 |
|--------|------|
| 自定义习惯 | 名称、图标、频率（每日/每周N次）、目标值 |
| 打卡方式 | 一键打卡 / 数值打卡（如：跑步 3.2km）/ 拍照打卡 |
| 连续记录 | 显示连续天数 🔥，断签提醒 |
| 日历热力图 | 类 GitHub 贡献图，一眼看出坚持情况 |
| 成就徽章 | 7天/21天/100天/365天里程碑徽章 |
| AI 鼓励 | 根据打卡数据生成个性化鼓励语 |

#### ④ 目标 / OKR 模块

| 功能点 | 说明 |
|--------|------|
| 目标设定 | 年/季/月/周目标，支持 SMART 原则引导 |
| 进度追踪 | 进度条 + 百分比，关联待办/打卡自动计算 |
| 里程碑 | 大目标拆解为关键结果（KR） |
| 复盘 | 每周/月 AI 自动生成复盘报告 |
| 倒计时 | 高考/考研/生日/纪念日等倒计时卡片 |

#### ⑤ 学习笔记模块

| 功能点 | 说明 |
|--------|------|
| 快速笔记 | 文字/语音/图片，AI 自动整理格式 |
| 错题本 | 拍照 → OCR → 自动归档到对应科目/知识点 |
| 知识卡片 | 类 Anki 间隔重复，AI 安排复习时间 |
| 学习时长 | 番茄钟计时，自动统计每日/每周学习时长 |
| AI 问答 | 对笔记内容提问，AI 基于你的笔记回答 |

#### ⑥ 健康 / 运动模块

| 功能点 | 说明 |
|--------|------|
| 运动记录 | 类型、时长、消耗卡路里 |
| 饮食记录 | 对话式："中午吃了一碗牛肉面+一杯豆浆" → AI 估算热量 |
| 体重/体脂 | 数值追踪 + 趋势曲线 |
| 饮水/睡眠 | 每日打卡 |
| AI 建议 | "本周运动量偏低，建议周末安排一次30分钟有氧" |

#### ⑦ 自定义模块

| 功能点 | 说明 |
|--------|------|
| 自由表单 | 用户自定义字段（文本/数字/日期/图片/选项） |
| 视图切换 | 列表 / 看板 / 日历 / 画廊 |
| AI 生成 | 描述需求 → AI 自动生成模块结构 |
| 示例 | 宠物喂养记录、追剧清单、读书清单、旅行规划… |

### 5.4 🤖 AI 能力层（核心差异化）

| AI 能力 | 说明 | 触发方式 |
|---------|------|----------|
| **主动提醒** | 不只是闹钟，而是带上下文的提醒："你已经连续学习2小时了，休息10分钟吧" | 自动 |
| **智能建议** | 基于数据给出可执行建议："本周支出偏多，建议周末自己做饭" | 自动/每日推送 |
| **周报/月报** | 一键生成图文复盘报告，可分享到朋友圈 | 用户触发 |
| **数据洞察** | 跨模块关联分析："你运动的那几天，学习效率平均高23%" | 用户提问/自动 |
| **长期记忆** | 记住用户偏好、习惯、目标，越用越懂你 | 持续 |
| **自然语言操作** | "帮我把明天的跑步改成游泳""这个月预算加500" | 对话 |
| **内容生成** | 生成学习计划、食谱、运动方案、周报文案等 | 对话 |

## 六、非功能性需求

|------|------|

| 多端同步 | 数据实时同步，切换设备无感 |

## 十一、风险 & 应对

| 风险 | 影响 | 应对 |
|------|------|------|
| AI 生成质量不稳定 | 用户首次体验差 → 流失 | 预设高质量模板兜底 + 人工审核热门模板 |
| 热点消退快 | 自然流量下降 | 持续产出场景化内容 + 模板社区 UGC 沉淀 |
| 用户"搭完就走" | 留存低 | 强化 AI 主动推送 + 打卡社交 + 数据沉淀成本 |
| 数据隐私顾虑 | 用户不敢用 | 端到端加密 + 一键删除 + 隐私白皮书 |
| 竞品跟进（扣子官方/Notion AI） | 差异化被抹平 | 深耕垂直场景模板 + 社区生态壁垒 |
