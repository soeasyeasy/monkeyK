# 第三章：文本标签

## 本章导读

在学这一章之前，你可能会有这些疑问：

- HTML 提供了哪些文本标签？它们各自有什么用途？
- 标题标签 h1 到 h6 有什么区别？应该怎么用？
- `<strong>` 和 `<b>` 有什么不同？`<em>` 和 `<i>` 呢？
- 如何正确引用别人的话？

这一章就是为了解答这些问题。我们会学习如何用 HTML 标签组织和格式化文本内容。

---

## 1 为什么需要文本标签？

### 痛点分析

想象一下，如果网页只有纯文本：

- 所有文字大小一样，无法区分标题和正文
- 没有段落分隔，内容密密麻麻堆在一起
- 无法强调重要内容，读者不知道重点在哪里
- 引用别人的话也无法区分

### 解决方案

HTML 提供了丰富的文本标签，让你可以给文字添加语义和结构。

> **一句话总结**：文本标签就像文章的格式，让内容有层次、有重点、易阅读。

打个比方：

> HTML 文本标签就像 Word 文档中的格式按钮：标题样式、加粗、斜体、引用、代码等。用对标签，内容就会清晰易读。

---

## 2 核心原理

### 概念解释

HTML 文本标签分为两大类：

1. **结构标签**：用于组织内容结构（标题、段落等）
2. **语义标签**：用于表达内容含义（强调、引用、代码等）

**结构标签**告诉浏览器"这是什么"（如标题、段落），**语义标签**告诉浏览器"这代表什么"（如重要、引用、代码）。

浏览器会根据标签的语义来渲染样式，但更重要的是，搜索引擎和屏幕阅读器也能理解内容的含义。

### 对比分析

| 标签类型 | 示例 | 主要用途 |
| --- | --- | --- |
| 标题 | `<h1>` - `<h6>` | 表示标题层级 |
| 段落 | `<p>` | 表示段落 |
| 强调 | `<strong>`、`<em>` | 表示重要性或强调 |
| 引用 | `<blockquote>`、`<q>` | 表示引用内容 |
| 代码 | `<code>`、`<pre>` | 表示代码 |

---

## 3 基础用法

### 标题标签

HTML 提供 6 级标题，从 `<h1>`（最重要）到 `<h6>`（最不重要）：

```html
<!-- 一级标题，通常页面只有一个 -->
<h1>网站主标题</h1>

<!-- 二级标题，用于章节 -->
<h2>章节标题</h2>

<!-- 三级标题，用于小节 -->
<h3>小节标题</h3>

<!-- 四级到六级标题，用于更深层次 -->
<h4>四级标题</h4>
<h5>五级标题</h5>
<h6>六级标题</h6>
```

> **原理**：标题标签不仅影响文字大小，更重要的是建立文档的大纲结构，帮助搜索引擎理解页面内容。

### 段落和换行

```html
<!-- 段落标签，自动添加前后间距 -->
<p>这是一个段落。段落是 HTML 中最基本的文本容器。</p>

<p>这是另一个段落。每个段落都会自动换行并添加间距。</p>

<!-- 强制换行，但不会创建新段落 -->
<p>这是一段文字。<br>这里换行了，但仍然是同一个段落。</p>

<!-- 水平分隔线，用于分隔内容 -->
<hr>

<p>这是分隔线下面的内容。</p>
```

### 文本格式化

```html
<!-- 强烈强调，通常显示为粗体 -->
<p><strong>重要提示：</strong>这是必须记住的内容。</p>

<!-- 强调，通常显示为斜体 -->
<p>我<em>非常</em>喜欢编程。</p>

<!-- 高亮文本，通常显示为黄色背景 -->
<p>关键词：<mark>HTML</mark>、<mark>CSS</mark>、<mark>JavaScript</mark></p>

<!-- 删除线，表示已删除的内容 -->
<p>原价：<del>¥100</del>，现价：¥80</p>

<!-- 下划线，表示插入的内容 -->
<p>最新版本支持<ins>暗黑模式</ins>。</p>

<!-- 下标 -->
<p>水的化学式：H<sub>2</sub>O</p>

<!-- 上标 -->
<p>面积公式：a<sup>2</sup> + b<sup>2</sup> = c<sup>2</sup></p>
```

### 引用

```html
<!-- 块级引用，用于较长的引用 -->
<blockquote>
  HTML 是构建网页的基础，没有 HTML，就没有现代互联网。
</blockquote>

<!-- 行内引用，用于短引用 -->
<p>爱因斯坦说：<q>想象力比知识更重要。</q></p>

<!-- 引用来源 -->
<p>参考资料：<cite>《HTML5 权威指南》</cite></p>
```

### 代码

```html
<!-- 行内代码，用于短代码片段 -->
<p>使用 <code>console.log()</code> 输出调试信息。</p>

<!-- 代码块，用于多行代码，保留格式 -->
<pre>
<code>
function hello() {
  console.log("Hello, World!");
}
</code>
</pre>
```

> **原理**：`<pre>` 标签会保留空格和换行，适合展示代码；`<code>` 标签表示这是代码内容。

---

## 4 核心知识点总结

| 标签 | 语义 | 显示效果 |
| --- | --- | --- |
| `<h1>` - `<h6>` | 标题（1-6级） | 字号递减，加粗 |
| `<p>` | 段落 | 自动换行和间距 |
| `<br>` | 换行 | 强制换行 |
| `<hr>` | 分隔线 | 水平线条 |
| `<strong>` | 强烈重要 | 粗体 |
| `<em>` | 强调 | 斜体 |
| `<mark>` | 高亮 | 黄色背景 |
| `<del>` | 删除 | 删除线 |
| `<ins>` | 插入 | 下划线 |
| `<sub>` | 下标 | 缩小并下沉 |
| `<sup>` | 上标 | 缩小并上升 |
| `<blockquote>` | 块级引用 | 缩进 |
| `<q>` | 行内引用 | 引号 |
| `<cite>` | 引用来源 | 斜体 |
| `<code>` | 代码 | 等宽字体 |
| `<pre>` | 预格式化文本 | 保留格式 |

## 5 新手常见误区

### 误区 1："h1 可以用多个"

**错！** 一个页面应该只有一个 `<h1>`，它是页面的主标题。使用多个 `<h1>` 会破坏文档结构，影响 SEO。

**错误写法 ❌**：
```html
<h1>产品介绍</h1>
<h1>功能特点</h1>  <!-- 错误！应该用 h2 -->
<h1>技术规格</h1>  <!-- 错误！应该用 h2 -->
```

**正确写法 ✅**：
```html
<h1>产品介绍</h1>
<h2>功能特点</h2>
<h2>技术规格</h2>
```

### 误区 2："用 `<b>` 代替 `<strong>`"

**错！** `<b>` 只是视觉上的粗体，没有语义；`<strong>` 表示内容"重要"，有语义。

**错误写法 ❌**：
```html
<p><b>注意：</b>请仔细阅读。</p>
```

**正确写法 ✅**：
```html
<p><strong>注意：</strong>请仔细阅读。</p>
```

### 误区 3："用 `<i>` 代替 `<em>`"

**错！** `<i>` 只是视觉上的斜体，没有语义；`<em>` 表示内容需要"强调"，有语义。

**错误写法 ❌**：
```html
<p>我<i>真的</i>很喜欢这个功能。</p>
```

**正确写法 ✅**：
```html
<p>我<em>真的</em>很喜欢这个功能。</p>
```

### 误区 4："段落之间用 `<br>` 分隔"

**错！** 应该用多个 `<p>` 标签来分隔段落，而不是用 `<br>`。

**错误写法 ❌**：
```html
<p>第一段内容。<br><br>第二段内容。</p>
```

**正确写法 ✅**：
```html
<p>第一段内容。</p>
<p>第二段内容。</p>
```

### 误区 5："`<pre>` 只用于代码"

不是的。`<pre>` 可以用于任何需要保留格式的文本，比如诗歌、ASCII 艺术等。

```html
<pre>
静夜思
床前明月光，
疑是地上霜。
举头望明月，
低头思故乡。
</pre>
```
