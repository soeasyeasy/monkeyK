# 第一章：HTML 简介

## 本章导读

在学这一章之前，你可能会有这些疑问：

- 什么是 HTML？它和网页有什么关系？
- 为什么学习前端要从 HTML 开始？
- HTML 是编程语言吗？它能做什么、不能做什么？
- 如何快速创建一个简单的网页？

这一章就是为了解答这些问题。我们会先搞清楚 **HTML 的本质**，再动手写第一个网页。

---

## 1.1 为什么需要 HTML？

### 痛点分析

想象一下，如果没有 HTML，我们的网页会是什么样子？

- 就像一本没有标题、没有段落、没有图片的书，所有内容堆在一起
- 用户无法区分标题和正文，阅读体验极差
- 搜索引擎无法理解页面内容，你的网站永远不会被搜到
- 屏幕阅读器无法识别内容结构，视障用户无法使用

### 解决方案

HTML 就像是给网页搭骨架，让杂乱的内容变得有条理。

> **一句话总结**：HTML 是网页的"骨架"，定义了内容的结构和含义。

打个比方：

> HTML 就像盖房子时搭的钢筋骨架。没有骨架，砖块和水泥就无处安放；没有 HTML，文字和图片就只是一堆散乱的数据。

## 1.2 HTML 核心原理

### 概念解释

HTML（HyperText Markup Language）是**超文本标记语言**，它不是编程语言，而是一种**标记语言**。

- **超文本**：不仅仅是文本，还包含链接、图片、视频等
- **标记**：使用标签（`<tag>`）来标记内容的含义和结构
- **语言**：一套标准化的语法规则

浏览器拿到 HTML 后，会按照标签的含义来解析和渲染页面。

### 对比分析

| 特性 | HTML | 编程语言（如 JavaScript） |
| --- | --- | --- |
| 本质 | 标记语言，描述结构 | 编程语言，描述逻辑 |
| 能力 | 定义页面结构和内容 | 实现交互和逻辑 |
| 执行方式 | 浏览器直接解析渲染 | 需要引擎解释执行 |
| 学习难度 | 低，只需记住标签 | 高，需要理解语法和逻辑 |

## 1.3 基础用法

### 第一个 HTML 页面

```html
<!-- 声明文档类型为 HTML5 -->
<!DOCTYPE html>

<!-- 根元素，告诉浏览器这是一个 HTML 文档 -->
<html lang="zh-CN">

<!-- 头部区域，包含页面的元数据（不会显示在页面上） -->
<head>
  <!-- 设置页面标题，会显示在浏览器标签上 -->
  <title>我的第一个网页</title>
</head>

<!-- 主体区域，包含页面的所有可见内容 -->
<body>
  <!-- 一级标题，最重要的标题 -->
  <h1>欢迎来到我的网站</h1>
  <!-- 段落，用于显示正文内容 -->
  <p>这是一个段落。</p>
</body>

</html>
```

> **原理**：浏览器从上到下依次解析标签，`<html>` 是根容器，`<head>` 存放配置信息，`<body>` 存放可见内容。

### 标签结构

```html
<!-- 标签由尖括号包裹，通常成对出现 -->
<标签名>内容</标签名>

<!-- 开始标签 -->
<p>

<!-- 结束标签（多了一个斜杠） -->
</p>

<!-- 自闭合标签（空元素，不需要结束标签） -->
<img src="image.jpg" alt="图片">
<br>
<hr>
```

## 1.4 核心知识点总结

| 知识点 | 说明 |
| --- | --- |
| HTML | 超文本标记语言，网页的骨架 |
| 标签 | 用 `<>` 包裹，标记内容的含义 |
| 元素 | 开始标签 + 内容 + 结束标签 |
| 属性 | 提供额外信息，如 `src="image.jpg"` |
| `<html>` | 根元素，包含整个文档 |
| `<head>` | 头部，存放元数据 |
| `<body>` | 主体，存放可见内容 |

## 1.5 新手常见误区

### 误区 1："HTML 是编程语言"

**错！** HTML 不是编程语言，它没有变量、循环、条件判断等编程特性。它只是用标签来描述内容结构的标记语言。

正确做法：把 HTML 理解为"网页结构描述语言"，配合 CSS（美化）和 JavaScript（交互）一起使用。

### 误区 2："标签顺序不重要"

不是的。HTML 标签必须正确嵌套，就像俄罗斯套娃一样。

**错误写法 ❌**：
```html
<div><p>内容</div></p>
```

**正确写法 ✅**：
```html
<div><p>内容</p></div>
```

### 误区 3："HTML 不需要语法规范"

**错！** HTML 虽然对语法要求相对宽松（浏览器会尽力容错），但不规范的代码会导致：
- 页面在不同浏览器显示不一致
- 搜索引擎无法正确解析
- 后期维护困难

正确做法：养成良好的编码习惯，使用正确的标签嵌套和闭合。

### 误区 4："HTML5 需要特殊配置"

不是的。HTML5 是 HTML 的最新标准，不需要安装任何插件或配置，现代浏览器都原生支持。只需要在文档开头声明 `<!DOCTYPE html>` 即可。
