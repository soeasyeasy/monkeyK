# 第一章：HTML 简介

## 什么是 HTML

HTML（HyperText Markup Language）是超文本标记语言，用于创建网页的标准标记语言。

## HTML 的作用

- 定义网页的结构和内容
- 使用标签描述网页元素
- 浏览器解析 HTML 并渲染页面

## 基本示例

```html
<!DOCTYPE html>
<html>
<head>
  <title>我的第一个网页</title>
</head>
<body>
  <h1>欢迎来到我的网站</h1>
  <p>这是一个段落。</p>
</body>
</html>
```

## HTML 历史

| 版本 | 年份 | 特点 |
| --- | --- | --- |
| HTML 1.0 | 1993 | 最初版本 |
| HTML 4.01 | 1999 | 广泛使用 |
| XHTML | 2000 | 更严格的语法 |
| HTML5 | 2014 | 现代标准 |

## 总结

HTML 是 Web 开发的基础，所有网页都由 HTML 构建。
