# 第4章：语音合成原理

## 本章导读

在学这一章之前，你可能会有这些疑问：

- 语音合成系统是怎么工作的？
- 什么是声码器？为什么需要它？
- WaveNet、Tacotron、FastSpeech 这些模型有什么区别？
- 如何让合成的声音更自然、更有感情？

这一章就是为了解答这些问题。我们会从 **TTS 系统架构** 讲起，再学习 **主流模型** 的原理，最后了解 **如何让声音更自然**。

---

## 1 为什么需要了解 TTS 原理？

### 痛点分析

很多开发者只会调用 API，遇到问题无法优化：

- 合成的声音机械感强，不自然
- 无法控制语速、音调、情感
- 无法处理多音字、数字、英文等特殊情况
- 无法选择合适的模型和音色

### 解决方案

理解 TTS 原理，你能：

- **选择合适的模型**：根据场景选 WaveNet、Tacotron 或 FastSpeech
- **优化合成效果**：调整参数，提升自然度
- **控制语音特征**：语速、音调、情感

打个比方：

> 学 TTS 原理就像学唱歌要懂发声原理。不懂原理，你只会跟着唱；懂了原理，你能控制气息、音调，唱得更好听。

> **一句话总结**：理解原理才能做出自然、动听的语音。

## 2 TTS 系统架构

### 2.1 整体架构

TTS 系统由三个核心模块组成：

```
文本输入 → 文本分析 → 声学模型 → 声码器 → 音频输出
```

| 模块 | 功能 | 类比 |
| --- | --- | --- |
| **文本分析** | 文本规范化、音素转换 | 把文字变成"发音说明书" |
| **声学模型** | 生成声学特征（如梅尔频谱） | 根据说明书生成"声音蓝图" |
| **声码器** | 把声学特征转换成波形 | 根据蓝图建造"声音房子" |

### 2.2 文本分析

**文本分析（Text Analysis）** 的任务是把原始文本转换成音素序列。

**主要步骤**：

#### 步骤 1：文本规范化（Text Normalization）

处理特殊文本：

| 原始文本 | 规范化后 |
| --- | --- |
| "123" | "一百二十三" |
| "2024年" | "二零二四年" |
| "￥100" | "一百元" |
| "Dr. Smith" | "Doctor Smith" |

#### 步骤 2：字音转换（G2P）

把文字转换成音素：

| 文字 | 音素 |
| --- | --- |
| "妈" | /m a/ |
| "爸" | /b a/ |
| "重"（多音字） | /ch ong/ 或 /zh ong/ |

**多音字处理**：根据上下文选择正确的发音。

#### 步骤 3：韵律预测

预测停顿、重音、语调：

```
今天/天气/很好// （/ 表示短停顿，// 表示长停顿）
```

### 2.3 声学模型

**声学模型（Acoustic Model）** 的任务是把音素序列转换成声学特征（如梅尔频谱）。

**常用声学模型**：

| 模型 | 说明 | 特点 |
| --- | --- | --- |
| **WaveNet** | 自回归模型 | 音质好，但速度慢 |
| **Tacotron** | 编码器-解码器 | 端到端，效果好 |
| **Tacotron 2** | 改进版 | 音质更好 |
| **FastSpeech** | 非自回归 | 速度快，效果接近 |
| **FastSpeech 2** | 改进版 | 更稳定，效果更好 |

### 2.4 声码器

**声码器（Vocoder）** 的任务是把声学特征转换成音频波形。

**为什么需要声码器？**

声学模型输出的是梅尔频谱等特征，不是直接的波形。声码器负责"重建"波形。

**常用声码器**：

| 声码器 | 说明 | 特点 |
| --- | --- | --- |
| **Griffin-Lim** | 传统算法 | 速度快，音质差 |
| **WaveNet** | 自回归 | 音质好，速度慢 |
| **WaveRNN** | 改进版 | 速度提升 |
| **MelGAN** | GAN 方法 | 速度快，音质好 |
| **HiFi-GAN** | 改进版 | 当前最常用，速度快音质好 |

## 3 主流模型详解

### 3.1 WaveNet

**WaveNet** 是 DeepMind 在 2016 年提出的模型。

**核心思想**：

- 自回归模型，逐个采样点生成波形
- 使用因果卷积（Causal Convolution）保证时序性
- 使用门控机制控制信息流

**WaveNet 的工作流程**：

1. 输入：条件特征（如音素、说话人）
2. 处理：多层因果卷积 + 门控
3. 输出：下一个采样点的概率分布
4. 采样：从分布中采样得到波形

**WaveNet 的优缺点**：

| 优点 | 缺点 |
| --- | --- |
| 音质非常好 | 生成速度极慢 |
| 能建模长距离依赖 | 计算量大 |
| 接近真人 | 不适合实时应用 |

### 3.2 Tacotron 2

**Tacotron 2** 是 Google 在 2017 年提出的模型。

**核心思想**：

- 编码器-解码器架构
- 编码器处理文本，解码器生成梅尔频谱
- 使用注意力机制对齐文本和音频
- 结合 WaveNet 声码器生成波形

**Tacotron 2 的工作流程**：

1. **编码器**：把文本嵌入转换成隐藏状态
2. **解码器**：逐步生成梅尔频谱帧
3. **注意力**：对齐文本和音频
4. **声码器**：WaveNet 把梅尔频谱转成波形

**Tacotron 2 的优缺点**：

| 优点 | 缺点 |
| --- | --- |
| 端到端训练 | 速度较慢 |
| 音质好 | 可能产生跳字、重复 |
| 效果稳定 | 需要大量数据 |

### 3.3 FastSpeech 2

**FastSpeech 2** 是微软在 2020 年提出的模型。

**核心思想**：

- 非自回归模型，并行生成
- 直接预测每个音素的时长
- 不需要注意力机制

**FastSpeech 2 的工作流程**：

1. **音素编码器**：把音素转换成隐藏状态
2. **时长预测器**：预测每个音素的持续时间
3. **长度调节器**：根据时长扩展隐藏状态
4. **声学解码器**：生成梅尔频谱
5. **声码器**：HiFi-GAN 转成波形

**FastSpeech 2 的优缺点**：

| 优点 | 缺点 |
| --- | --- |
| 生成速度快（100x+） | 音质略逊于 Tacotron 2 |
| 稳定性好 | 需要时长标注 |
| 可控性强 | 复杂度略高 |

## 5 语音特征控制

### 5.1 语速控制

**语速** 指说话的快慢。

**控制方法**：

1. **时长预测**：调整音素持续时间
2. **时间拉伸**：对波形进行拉伸/压缩
3. **参数调节**：调整模型的速度参数

### 5.2 音调控制

**音调** 指声音的高低。

**控制方法**：

1. **基频（F0）调节**：直接修改基频曲线
2. **音调嵌入**：使用音调嵌入向量
3. **变调不变速**：使用 PSOLA 等算法

### 5.3 情感控制

**情感** 指语音的情绪色彩（高兴、悲伤、愤怒等）。

**控制方法**：

1. **情感嵌入**：使用情感嵌入向量
2. **风格迁移**：从参考音频提取风格
3. **多任务学习**：同时预测内容和情感

## 6 评估指标

### 6.1 主观评估

**MOS（Mean Opinion Score）** 是最常用的主观指标。

**评分标准**：

| 分数 | 说明 |
| --- | --- |
| 5 | 完美，接近真人 |
| 4 | 好，轻微机械感 |
| 3 | 中等，有明显机械感 |
| 2 | 差，难以接受 |
| 1 | 很差，无法理解 |

### 6.2 客观评估

| 指标 | 说明 |
| --- | --- |
| **MCD（Mel Cepstral Distortion）** | 梅尔倒谱失真，衡量频谱差异 |
| **F0 RMSE** | 基频均方根误差，衡量音调准确性 |
| **RTF（Real-Time Factor）** | 实时率，衡量生成速度 |

## 8 新手常见误区

### 误区 1："WaveNet 是最好的模型"

**不一定！** WaveNet 音质好，但速度极慢，不适合实时应用。

正确做法：根据场景选择模型。实时应用用 FastSpeech 2，离线高质量用 WaveNet。

### 误区 2："声码器不重要"

**错！** 声码器对音质影响很大。

差的声码器（如 Griffin-Lim）会让好模型也输出差音质。推荐用 HiFi-GAN。

### 误区 3："不需要文本分析"

**错！** 文本分析质量直接影响合成效果。

多音字、数字、英文处理不好，会导致发音错误。

### 误区 4："语速越快越好"

**不一定！** 语速过快会降低清晰度，过慢会显得拖沓。

正常语速是 150-200 字/分钟（中文）。

### 误区 5："情感控制很难"

**不难！** 现代模型支持情感嵌入，只需提供情感标签即可。

关键是训练数据要有情感标注。

## 9 动手练习

### 练习 1：概念理解

用自己的话解释：
1. 声学模型和声码器的区别
2. 自回归和非自回归的区别
3. 为什么 FastSpeech 2 比 Tacotron 2 快？

<details>
<summary>点击查看答案</summary>

1. **声学模型 vs 声码器**：
   - 声学模型：把音素转成梅尔频谱（生成"蓝图"）
   - 声码器：把梅尔频谱转成波形（建造"房子"）

2. **自回归 vs 非自回归**：
   - 自回归：逐个生成，前一步依赖后一步（慢）
   - 非自回归：并行生成，所有帧同时生成（快）

3. **FastSpeech 2 更快的原因**：
   - 非自回归架构，并行生成
   - 直接预测音素时长，不需要逐步对齐
   - 生成速度是 Tacotron 2 的 100 倍以上

- 用户可以调节语速和音调

**系统架构图**：

```
文本输入 → 文本分析 → 情感编码器 → FastSpeech 2 → HiFi-GAN → 音频输出
                              ↓
                         语速/音调控制
```

**模块设计**：

| 模块 | 功能 | 技术选型 |
| --- | --- | --- |

**工作流程**：
1. 用户输入文本和情感标签
2. 文本分析模块处理文本
3. 情感编码器生成情感特征

5. 语速/音调控制器调整参数
6. HiFi-GAN 生成波形
7. 输出音频
