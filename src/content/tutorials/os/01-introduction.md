# 第一章：操作系统概述

## 什么是操作系统

操作系统（Operating System，简称 OS）是管理计算机硬件与软件资源的系统软件，同时也是计算机系统的内核与基石。

### 操作系统的定义

操作系统是一组**控制和管理计算机硬件和软件资源、合理地对各类作业进行调度、以及方便用户使用的程序的集合**。

::: tip
操作系统是用户和计算机硬件之间的桥梁，它隐藏了硬件的复杂性，为用户提供了友好的接口。
:::

### 操作系统的目标

| 目标         | 说明                               |
| ------------ | ---------------------------------- |
| **方便性**   | 提供友好的用户界面，简化计算机操作 |
| **有效性**   | 高效利用 CPU、内存、I/O 设备等资源 |
| **可扩展性** | 支持新硬件和功能的添加             |
| **开放性**   | 遵循国际标准，支持互操作性         |

## 操作系统的功能

操作系统主要提供以下五大功能：

### 1. 处理器管理（CPU 管理）

- **进程控制**：创建、撤销、挂起、唤醒进程
- **进程同步**：协调多个进程的执行顺序
- **进程通信**：实现进程间的信息交换
- **调度**：决定哪个进程使用 CPU

### 2. 存储器管理（内存管理）

- **内存分配与回收**：为程序分配内存空间
- **地址映射**：将逻辑地址转换为物理地址
- **内存保护**：防止进程访问非法内存区域
- **内存扩充**：利用虚拟内存技术扩展可用内存

### 3. 设备管理（I/O 管理）

- **设备分配**：为进程分配 I/O 设备
- **设备驱动**：控制硬件设备的工作
- **缓冲管理**：提高 I/O 效率
- **设备独立性**：提供统一的设备访问接口

### 4. 文件管理

- **文件存储空间管理**：管理磁盘空间
- **目录管理**：组织文件结构
- **文件的读写管理和保护**：控制文件访问

### 5. 用户接口

- **命令接口**：命令行界面（CLI）
- **图形用户接口**：图形界面（GUI）
- **程序接口**：系统调用（System Call）

## 操作系统的发展历程

### 第一代（1945-1955）：手工操作

- 使用插线板和开关编程
- 没有操作系统
- 单用户、单任务

### 第二代（1955-1965）：批处理系统

- 使用穿孔卡片
- 引入了监控程序
- 提高了 CPU 利用率

### 第三代（1965-1980）：多道程序系统

- 多道程序设计
- 分时系统
- 实时系统
- 出现了 UNIX 操作系统

### 第四代（1980-至今）：现代操作系统

- 图形用户界面（GUI）
- 网络操作系统
- 分布式操作系统
- 移动操作系统（iOS、Android）

## 操作系统的分类

### 按使用场景分类

| 类型               | 特点                       | 典型代表              |
| ------------------ | -------------------------- | --------------------- |
| **桌面操作系统**   | 面向个人用户，提供图形界面 | Windows、macOS、Linux |
| **服务器操作系统** | 高稳定性、高并发、安全性   | Linux、Windows Server |
| **嵌入式操作系统** | 资源受限、实时性要求高     | RTOS、嵌入式 Linux    |
| **移动操作系统**   | 触摸界面、低功耗           | iOS、Android          |
| **实时操作系统**   | 严格的时间约束             | VxWorks、QNX          |

### 按架构分类

#### 宏内核（Monolithic Kernel）

- 所有功能都在内核空间运行
- 性能高，但耦合度大
- 代表：Linux、UNIX

#### 微内核（Microkernel）

- 只保留核心功能在内核
- 其他功能在用户空间运行
- 代表：Minix、QNX

#### 混合内核（Hybrid Kernel）

- 结合宏内核和微内核的特点
- 代表：Windows NT、macOS

## 本章小结

- 操作系统是管理计算机硬件与软件资源的系统软件
- 操作系统提供五大功能：处理器管理、存储器管理、设备管理、文件管理、用户接口
- 操作系统经历了从手工操作到现代操作系统的四个发展阶段
- 操作系统按使用场景可分为桌面、服务器、嵌入式、移动、实时等类型
- 操作系统架构主要有宏内核、微内核、混合内核三种
