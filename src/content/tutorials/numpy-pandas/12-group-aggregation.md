## 1 为什么需要分组与聚合？

### 痛点分析

假设你有一份销售数据，老板问你："每个地区的总销售额是多少？"

```python
# ❌ 不用 groupby：手动循环，又慢又乱
import pandas as pd

df = pd.DataFrame({
    '地区': ['北京', '上海', '北京', '上海', '北京'],
    '销售额': [100, 200, 150, 300, 250]
})

# 手动按地区分组求和
regions = df['地区'].unique()  # 先找出所有地区
result = {}
for region in regions:
    total = df[df['地区'] == region]['销售额'].sum()  # 每个地区单独筛选求和
    result[region] = total
print(result)  # {'北京': 500, '上海': 500}
```

```python
# ✅ 用 groupby：一行代码搞定
result = df.groupby('地区')['销售额'].sum()
print(result)
# 地区
# 北京    500
# 上海    500
```

> 一句话总结：groupby 让你告别手动循环，一行代码完成分组统计。

### 生活化类比

打个比方：

> 想象你面前有一筐混在一起的水果——苹果、香蕉、橘子。
> groupby 就像把水果按种类分成三堆，然后你可以对每堆分别操作：
> - 每堆称一下总重量（sum）
> - 每堆看看平均单个有多重（mean）
> - 每堆数一下有几个（count）
> - 每堆找出最重的那个（max）
>
> 这就是"拆分-应用-合并"的过程。

### 代码对比

| 操作方式 | 代码量 | 可读性 | 性能 |
| --- | --- | --- | --- |
| 手动循环分组 | 多行 | 差 | 慢 |
| groupby | 一行 | 好 | 快（底层 C 实现） |

## 2 核心原理：拆分-应用-合并

### 通俗类比

groupby 的工作分三步：

```
第一步：拆分（Split）  —— 按某一列的值，把数据分成若干组
第二步：应用（Apply）  —— 对每一组分别执行某种计算
第三步：合并（Combine）—— 把各组的结果拼在一起返回
```

就像学校运动会：
- 拆分：按班级把学生分开（一班一组，二班一组）
- 应用：分别计算每个班的总分、平均分
- 合并：把各班成绩汇总成一张表

### 对比表格：groupby 核心概念

| 概念 | 说明 | 类比 |
| --- | --- | --- |
| 分组键 | 按哪一列分组 | 按水果种类分堆 |
| 聚合 | 对每组做计算 | 每堆分别称重 |
| GroupBy 对象 | 分组后还没计算 | 分好堆但还没称 |
| 聚合结果 | 计算后的最终结果 | 每堆的重量 |

### 对比表格：常用聚合函数

| 函数 | 作用 | 示例 |
| --- | --- | --- |
| sum() | 求和 | 每组总销售额 |
| mean() | 平均值 | 每组平均薪资 |
| count() | 计数 | 每组有多少条记录 |
| min() | 最小值 | 每组最低分 |
| max() | 最大值 | 每组最高分 |
| std() | 标准差 | 每组数据的波动程度 |
| median() | 中位数 | 每组中间值 |
| first() | 第一个值 | 每组第一条记录 |
| last() | 最后一个值 | 每组最后一条记录 |

## 3 基础用法

### 单列分组

```python
import pandas as pd

# 创建示例数据
df = pd.DataFrame({
    '部门': ['技术', '技术', '市场', '市场', '技术', '人事'],
    '姓名': ['小明', '小红', '小刚', '小丽', '小王', '小张'],
    '薪资': [15000, 25000, 18000, 30000, 20000, 12000],
    '年龄': [25, 30, 28, 35, 22, 27]
})

# 第一步：创建 GroupBy 对象（此时还没计算）
grouped = df.groupby('部门')  # 按部门分组，返回一个分组对象

# 第二步：对分组对象应用聚合函数
print(grouped['薪资'].sum())    # 每个部门的薪资总和
# 部门
# 人事    12000
# 市场    48000
# 技术    60000

print(grouped['薪资'].mean())   # 每个部门的平均薪资
# 部门
# 人事    12000.0
# 市场    24000.0
# 技术    20000.0

print(grouped['薪资'].count())  # 每个部门有多少人
# 部门
# 人事    1
# 市场    2
# 技术    3
```

### 多列分组

```python
import pandas as pd

df = pd.DataFrame({
    '部门': ['技术', '技术', '市场', '市场', '技术', '人事'],
    '性别': ['男', '女', '男', '女', '男', '男'],
    '薪资': [15000, 25000, 18000, 30000, 20000, 12000]
})

# 按部门和性别两列分组
result = df.groupby(['部门', '性别'])['薪资'].mean()
print(result)
# 部门  性别
# 人事  男     12000.0
# 市场  女     30000.0
#       男     18000.0
# 技术  女     25000.0
#       男     17500.0

# 重置索引，变成普通 DataFrame
result = result.reset_index()
print(result)
#    部门 性别     薪资
# 0  人事  男  12000.0
# 1  市场  女  30000.0
# 2  市场  男  18000.0
# 3  技术  女  25000.0
# 4  技术  男  17500.0
```

### agg() 方法：多函数聚合

```python
import pandas as pd

df = pd.DataFrame({
    '部门': ['技术', '技术', '市场', '市场', '技术'],
    '姓名': ['小明', '小红', '小刚', '小丽', '小王'],
    '薪资': [15000, 25000, 18000, 30000, 20000]
})

# 一次使用多个聚合函数
stats = df.groupby('部门')['薪资'].agg(['sum', 'mean', 'max', 'min', 'count'])
print(stats)
#       sum     mean    max    min  count
# 部门
# 市场  48000  24000.0  30000  18000      2
# 技术  60000  20000.0  25000  15000      3

# 对不同列使用不同的聚合函数
result = df.groupby('部门').agg({
    '薪资': ['sum', 'mean'],    # 薪资求总和和平均值
    '姓名': 'count'             # 姓名计数（即人数）
})
print(result)
#       薪资              姓名
#        sum     mean   count
# 部门
# 市场  48000  24000.0       2
# 技术  60000  20000.0       3

# 使用命名聚合（Pandas 推荐写法）
result = df.groupby('部门').agg(
    薪资总和=('薪资', 'sum'),      # 新列名 = (原列名, 聚合函数)
    平均薪资=('薪资', 'mean'),
    人数=('姓名', 'count')
).reset_index()
print(result)
#    部门  薪资总和  平均薪资  人数
# 0  市场   48000  24000.0     2
# 1  技术   60000  20000.0     3
```

### 自定义聚合函数

```python
import pandas as pd

df = pd.DataFrame({
    '部门': ['技术', '技术', '市场', '市场', '技术'],
    '薪资': [15000, 25000, 18000, 30000, 20000]
})

# 自定义：计算薪资极差（最大值减最小值）
def salary_range(group):
    return group.max() - group.min()  # 极差 = 最大值 - 最小值

result = df.groupby('部门')['薪资'].agg(
    总和='sum',           # 内置函数
    极差=salary_range     # 自定义函数
)
print(result)
#       总和    极差
# 部门
# 市场  48000  12000
# 技术  60000  10000
```

### 透视表：pivot_table()

```python
import pandas as pd

df = pd.DataFrame({
    '姓名': ['小明', '小红', '小刚', '小丽', '小王', '小张'],
    '部门': ['技术', '市场', '技术', '市场', '技术', '市场'],
    '年份': [2023, 2023, 2024, 2024, 2023, 2024],
    '薪资': [15000, 18000, 17000, 22000, 20000, 25000]
})

# 创建透视表：行=部门，列=年份，值=薪资的平均值
pt = pd.pivot_table(df, index='部门', columns='年份', values='薪资', aggfunc='mean')
print(pt)
# 年份     2023      2024
# 部门
# 市场  18000.0   23500.0   <-- 市场部 2023 年均薪 18000，2024 年均薪 23500
# 技术  17500.0   17000.0   <-- 技术部 2023 年均薪 17500，2024 年均薪 17000

# 使用多种聚合函数
pt2 = pd.pivot_table(df, index='部门', columns='年份', values='薪资', aggfunc=['sum', 'mean'])
print(pt2)

# 指定填充值（把 NaN 替换为 0）
pt3 = pd.pivot_table(df, index='部门', columns='年份', values='薪资', fill_value=0)
print(pt3)
```

### 交叉表：crosstab()

```python
import pandas as pd

df = pd.DataFrame({
    '姓名': ['小明', '小红', '小刚', '小丽', '小王', '小张'],
    '部门': ['技术', '市场', '技术', '市场', '技术', '市场'],
    '性别': ['男', '女', '男', '女', '男', '男']
})

# 交叉表：统计部门和性别的分布情况
ct = pd.crosstab(df['部门'], df['性别'])
print(ct)
# 性别  女  男
# 部门
# 市场   2  1    <-- 市场部有 2 名女性，1 名男性
# 技术   0  3    <-- 技术部有 0 名女性，3 名男性

# 添加合计行和列
ct2 = pd.crosstab(df['部门'], df['性别'], margins=True)
print(ct2)
# 性别  女  男  All
# 部门
# 市场   2  1    3
# 技术   0  3    3
# All  2  4    6
```

## 4 对比表格

### groupby 常用操作速查

| 操作 | 代码 | 说明 |
| --- | --- | --- |
| 单列分组 | df.groupby('列名') | 按一列分组 |
| 多列分组 | df.groupby(['列1', '列2']) | 按多列分组 |
| 分组后求和 | groupby('列')['值列'].sum() | 每组求和 |
| 分组后求均值 | groupby('列')['值列'].mean() | 每组求均值 |
| 多函数聚合 | groupby('列')['值列'].agg([...]) | 同时使用多个聚合函数 |
| 命名聚合 | groupby('列').agg(新名=('列', '函数')) | 给结果列起名字 |
| 透视表 | pd.pivot_table(df, index, columns, values) | 类似 Excel 透视表 |
| 交叉表 | pd.crosstab(行, 列) | 统计频率分布 |

### 透视表 vs 交叉表

| 特性 | pivot_table | crosstab |
| --- | --- | --- |
| 用途 | 数据汇总、多维分析 | 频率统计、分布查看 |
| 数据来源 | 需要传入 DataFrame | 直接传入列数据 |
| 灵活度 | 高（可自定义聚合函数） | 低（默认计数） |
| 类比 | Excel 透视表 | 频率统计表 |

## 5 新手常见误区

### 误区 1："groupby 之后直接就能看到结果"

错！groupby 返回的是一个分组对象，不是最终结果。你必须对它调用聚合函数：

```python
# ❌ 错误：以为 groupby 就是最终结果
result = df.groupby('部门')
print(result)  # 输出的是一个 DataFrameGroupBy 对象，不是数据

# ✅ 正确：groupby 之后必须聚合
result = df.groupby('部门')['薪资'].sum()  # 调用 sum() 才能得到结果
print(result)
```

### 误区 2："透视表的 index 和 columns 搞反了"

index 是行方向，columns 是列方向，搞反了透视表就完全不一样：

```python
# ❌ 把行列搞反了
pt = pd.pivot_table(df, index='年份', columns='部门', values='薪资')  # 行是年份，列是部门

# ✅ 想清楚再写：我想让什么在行，什么在列
pt = pd.pivot_table(df, index='部门', columns='年份', values='薪资')  # 行是部门，列是年份
```

### 误区 3："agg 里只能用字符串指定函数"

不是的。agg 里可以传字符串、函数、甚至 lambda：

```python
# ✅ 三种方式都可以
df.groupby('部门')['薪资'].agg('sum')                    # 字符串
df.groupby('部门')['薪资'].agg(sum)                      # 内置函数
df.groupby('部门')['薪资'].agg(lambda x: x.max() - x.min())  # lambda 表达式
```

### 误区 4："分组聚合后索引不需要处理"

groupby 之后，分组列会变成索引（MultiIndex），如果不处理，后续操作可能不方便：

```python
# 分组后，部门变成了索引
result = df.groupby('部门')['薪资'].mean()
print(result.index)  # Index(['市场', '技术'], name='部门')

# ✅ 用 reset_index 把索引变回普通列
result = result.reset_index()
print(result.columns)  # Index(['部门', '薪资'], dtype='object')
```

## 6 动手练习

### 练习 1（基础）：单列分组统计

创建一个包含学生成绩的 DataFrame，按班级分组，计算每个班的平均分、最高分和人数。

<details>
<summary>点击查看答案</summary>

```python
import pandas as pd

# 创建学生成绩数据
df = pd.DataFrame({
    '班级': ['一班', '一班', '一班', '二班', '二班', '二班'],
    '姓名': ['小明', '小红', '小刚', '小丽', '小王', '小张'],
    '成绩': [85, 92, 78, 90, 88, 95]
})

# 按班级分组，计算平均分、最高分、人数
result = df.groupby('班级')['成绩'].agg(
    平均分='mean',    # 计算平均分
    最高分='max',     # 计算最高分
    人数='count'      # 统计人数
).reset_index()

print(result)
#    班级  平均分  最高分  人数
# 0  一班  85.0    92     3
# 1  二班  91.0    95     3
```

### 练习 2（进阶）：多列分组 + 命名聚合

有一份销售数据，按"地区"和"产品类别"分组，计算总销售额和订单数量，并给结果列起中文名。

<details>
<summary>点击查看答案</summary>

```python
import pandas as pd

# 创建销售数据
df = pd.DataFrame({
    '地区': ['华东', '华东', '华北', '华北', '华东', '华北'],
    '产品': ['手机', '电脑', '手机', '电脑', '平板', '手机'],

```

### 练习 3（挑战）：透视表 + 交叉表综合

有一份员工数据，要求：
1. 用透视表查看各部门、各年份的平均薪资
2. 用交叉表查看各部门、各性别的员工分布
3. 交叉表要包含行列合计

<details>
<summary>点击查看答案</summary>

```python
import pandas as pd

# 创建员工数据
df = pd.DataFrame({
    '姓名': ['小明', '小红', '小刚', '小丽', '小王', '小张', '小陈', '小林'],
    '部门': ['技术', '技术', '市场', '市场', '技术', '人事', '人事', '技术'],
    '性别': ['男', '女', '男', '女', '男', '男', '女', '男'],
    '年份': [2023, 2023, 2023, 2023, 2024, 2024, 2024, 2024],
    '薪资': [15000, 20000, 18000, 22000, 17000, 13000, 14000, 19000]
})

# 1. 透视表：部门 x 年份，值为薪资均值
pt = pd.pivot_table(
    df,
    index='部门',        # 行：部门
    columns='年份',      # 列：年份
    values='薪资',       # 值：薪资
    aggfunc='mean'       # 聚合方式：平均值
)
print("透视表 - 各部门各年份平均薪资：")
print(pt)

# 2. 交叉表：部门 x 性别
ct = pd.crosstab(
    df['部门'],    # 行：部门
    df['性别'],    # 列：性别
    margins=True   # 添加合计行和列
)
print("\n交叉表 - 各部门性别分布：")
print(ct)
```

</details>
