## 1 为什么需要 NLP？

### 痛点分析

想象一下：你每天刷微博、看新闻、读论文，轻松就能理解文字内容。但对计算机来说，这些文字只是一堆毫无意义的字符。

**没有 NLP 的世界**：
- 搜索引擎无法理解你的搜索意图，只能机械匹配关键词
- 智能客服只能回复固定话术，无法理解你的问题
- 机器翻译质量极差，翻译出来的句子读不懂
- 语音助手听不懂你说话，更无法回答问题
- 社交媒体无法自动识别垃圾评论和有害内容

### 解决方案

NLP（自然语言处理）就是 **教计算机"理解"人类语言**——让它能读懂文字、听懂语音、甚至生成流畅的文本。

打个比方：

> 教计算机理解语言，就像教外国朋友学中文。你先教他拼音（分词），再教他词汇（词向量），然后教他语法（句法分析），最后让他多读多练（模型训练）。练得多了，他就能看懂中文文章、回答中文问题了。NLP 也是同样的道理——让计算机学会人类语言的结构和规律。

> **一句话总结**：NLP 让机器拥有了"语言大脑"，能理解和生成人类语言。

## 2 核心原理

### 概念解释

**自然语言处理（Natural Language Processing，简称 NLP）** 是人工智能的一个分支，研究如何让计算机理解、处理、生成人类语言。

简单来说，NLP 要解决三类问题：

| 问题类型 | 说明 | 生活例子 |
| --- | --- | --- |
| **理解文本** | 文本分类、情感分析 | 这条评论是好评还是差评？ |
| **提取信息** | 命名实体识别、关键词提取 | 这句话里提到了哪些人名、地名？ |
| **生成文本** | 机器翻译、文本摘要、对话生成 | 把这篇英文论文翻译成中文 |

### 发展简史

NLP 的发展可以分为几个阶段：

| 阶段 | 时间 | 关键事件 |
| --- | --- | --- |
| 规则时代 | 1950s-1980s | 基于人工编写规则，如正则表达式、上下文无关文法 |
| 统计时代 | 1990s-2000s | 基于统计模型，如 HMM、CRF、N-gram 语言模型 |
| 深度学习时代 | 2010-2017 | 基于神经网络，如 Word2Vec、RNN、LSTM、Seq2Seq |
| 预训练时代 | 2018-至今 | 基于 Transformer 的预训练模型，如 BERT、GPT、LLM |

### 技术栈概览

学 NLP，你需要掌握这些工具：

| 工具 | 用途 | 难度 |
| --- | --- | --- |
| **Python** | 编程语言，NLP 领域的主流语言 | 入门简单 |
| **NLTK / spaCy** | 传统 NLP 工具库，做分词、词性标注等基础任务 | 入门简单 |
| **Jieba** | 中文分词库，处理中文文本必备 | 入门简单 |
| **NumPy / Pandas** | 数值计算和数据处理库 | 入门简单 |
| **PyTorch / TensorFlow** | 深度学习框架，做高级 NLP 任务 | 需要基础 |
| **Hugging Face Transformers** | 预训练模型库，快速使用 BERT、GPT 等模型 | 需要基础 |

## 3 应用领域

NLP 的应用无处不在，以下是主要领域：

### 3.1 搜索引擎

搜索引擎是 NLP 最成功的应用之一：
- **查询理解**：理解用户搜索意图，纠正拼写错误
- **文本匹配**：将查询与网页内容进行语义匹配
- **知识图谱**：从网页中提取实体和关系，构建知识库
- **智能问答**：直接返回答案而非网页链接

### 3.2 智能客服

从人工客服到智能助手：
- **意图识别**：理解用户想问什么问题
- **槽位填充**：提取问题中的关键信息（如时间、地点）
- **对话管理**：维护对话状态，引导用户完成任务
- **知识问答**：基于知识库回答用户问题

### 3.3 机器翻译

让跨语言交流变得简单：
- **神经机器翻译**：Google 翻译、百度翻译等
- **实时翻译**：语音翻译、摄像头翻译
- **文档翻译**：整篇文档的自动翻译

### 3.4 内容审核

维护网络环境的安全：
- **垃圾邮件检测**：自动识别和过滤垃圾邮件
- **敏感内容过滤**：识别暴力、色情、政治敏感内容
- **虚假新闻检测**：识别谣言和虚假信息
- **评论审核**：自动删除恶意评论

### 3.5 文本生成

让机器也能"写文章"：
- **文本摘要**：自动提取长文章的核心内容
- **新闻生成**：根据数据自动生成新闻报道
- **创意写作**：辅助创作小说、诗歌、剧本
- **代码生成**：根据自然语言描述生成代码

### 3.6 语音助手

让机器"听懂"你说话：
- **语音识别（ASR）**：将语音转换为文本（Siri、小爱同学）
- **自然语言理解（NLU）**：理解语音指令的含义
- **语音合成（TTS）**：将文本转换为语音回复

## 4 基础用法

### 第一个 NLP 程序预览

虽然这一章主要是概念介绍，但我们先预览一下后面会用到的代码长什么样：

```python
# 导入 jieba 分词库（中文 NLP 的第一步：分词）
import jieba

# 定义一句中文文本
text = "自然语言处理是人工智能的重要方向"

# 使用 jieba 进行分词（把句子切成词语）
# 就像把一句话拆成一个个词块
words = jieba.lcut(text)

# 打印分词结果
print("分词结果：", words)
# 输出：['自然语言处理', '是', '人工智能', '的', '重要', '方向']

# 统计词频（看看哪些词出现得最多）
from collections import Counter
word_freq = Counter(words)
print("词频统计：", word_freq)
# 输出：Counter({'自然语言处理': 1, '是': 1, '人工智能': 1, '的': 1, '重要': 1, '方向': 1})
```

> **原理**：就这么简单！NLP 的第一步永远是 **分词**——把连续的文本切成有意义的词语。后面所有章节都是在这个基础上做文章。

## 6 新手常见误区

### 误区 1："NLP 就是教计算机说人话"

**错！** NLP 不仅仅是让计算机"说话"，更重要的是让计算机"理解"语言。文本分类、情感分析、信息提取等任务，都是让计算机理解文本的含义，而不是生成文本。

### 误区 2："学 NLP 必须先学语言学"

不是的。虽然了解语言学知识有帮助，但现代 NLP 更多依赖数学和计算机科学。你不需要成为语言学家，只需要掌握基本的编程和机器学习知识就能入门。

### 误区 3："NLP 只能处理英文"

**错！** NLP 可以处理任何语言。虽然英文 NLP 起步早、资源多，但中文、日文、法文等语言的 NLP 技术也已经非常成熟。本教程会同时覆盖中英文 NLP 技术。

### 误区 4："有了大语言模型，不需要学传统 NLP 了"

不是的。大语言模型（如 GPT）确实很强大，但传统 NLP 技术（如分词、词性标注、句法分析）仍然是基础。理解这些基础概念，才能更好地使用和优化大模型。

### 误区 5："NLP 模型越大越好"

**错！** 模型大小需要根据任务需求权衡。小模型速度快、资源消耗少，适合简单任务；大模型效果好，但成本高。实际应用中，要根据场景选择合适的模型。

import jieba

texts = [

### 练习 2：进阶练习 - 统计词频并可视化

**题目**：读取一段文本，统计词频最高的 10 个词，并用柱状图展示。

提示：使用 `collections.Counter` 统计词频，使用 `matplotlib` 绘图。

<details>
<summary>点击查看答案</summary>

```python
# 导入所需库
import jieba
from collections import Counter
import matplotlib.pyplot as plt

# 设置中文字体（避免中文显示为方框）
plt.rcParams['font.sans-serif'] = ['SimHei']

# 定义一段文本
text = """
自然语言处理是人工智能的重要分支。
自然语言处理包括文本分类、情感分析、机器翻译等任务。
学习自然语言处理需要掌握 Python 编程和机器学习基础。
"""

# 分词
words = jieba.lcut(text)

# 过滤停用词（如"是"、"的"、"和"等）
stop_words = {'是', '的', '和', '等', '需要', '掌握', '包括', '学习'}
filtered_words = [w for w in words if w not in stop_words and len(w) > 1]

# 统计词频
word_freq = Counter(filtered_words)

# 获取词频最高的 10 个词
top_10 = word_freq.most_common(10)

# 提取词和频率
words_list = [item[0] for item in top_10]
freq_list = [item[1] for item in top_10]

# 绘制柱状图
plt.figure(figsize=(10, 6))
plt.bar(words_list, freq_list, color='skyblue')
plt.xlabel('词语')
plt.ylabel('出现次数')
plt.title('文本词频统计 Top 10')
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
```

</details>

### 练习 3（挑战）：综合练习 - 简单的关键词提取器

**题目**：实现一个简单的关键词提取器，要求：
1. 对输入文本进行分词
2. 过滤停用词和标点符号
3. 按词频排序，返回 Top 5 关键词
4. 测试以下文本："机器学习是人工智能的子领域。机器学习专注于让计算机系统从数据中学习。机器学习算法使用数据来改进性能。"

<details>
<summary>点击查看答案</summary>

```python
# 导入所需库
import jieba
from collections import Counter
import re

def extract_keywords(text, top_n=5):
    """
    从文本中提取关键词
    
    参数：
        text: 输入文本
        top_n: 返回的关键词数量
    
    返回：
        关键词列表
    """
    # 定义停用词表
    stop_words = {
        '是', '的', '了', '在', '和', '与', '或', '等', '从', '让', '使用',
        '来', '专注于', '算法', '领域', '系统', '性能', '改进', '子', '人工',
        '智能', '数据', '一个', '这个', '那个', '什么', '怎么', '为什么'
    }
    
    # 分词
    words = jieba.lcut(text)
    
    # 过滤：去除停用词、标点符号、单字词
    filtered_words = []
    for word in words:
        # 去除空白字符
        word = word.strip()
        # 过滤条件：长度>1、不是停用词、不是纯标点、不是纯数字
        if (len(word) > 1 and 
            word not in stop_words and 
            not re.match(r'^[^\w\s]+$', word) and  # 不是纯标点
            not re.match(r'^\d+$', word)):  # 不是纯数字
            filtered_words.append(word)
    
    # 统计词频
    word_freq = Counter(filtered_words)
    
    # 返回 Top N 关键词
    keywords = [item[0] for item in word_freq.most_common(top_n)]
    
    return keywords

# 测试文本
test_text = """
机器学习是人工智能的子领域。机器学习专注于让计算机系统从数据中学习。
机器学习算法使用数据来改进性能。深度学习是机器学习的一个分支，
它使用神经网络来模拟人脑的工作方式。
"""

# 提取关键词
keywords = extract_keywords(test_text, top_n=5)
print(f"关键词：{keywords}")
# 输出示例：['机器学习', '数据', '学习', '人工智能', '神经网络']
```

</details>
