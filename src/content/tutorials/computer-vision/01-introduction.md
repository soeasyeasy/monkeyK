## 1 为什么需要计算机视觉？

### 痛点分析

想象一下：你每天睁开眼睛，就能认出身边的人、看懂路牌、避开障碍物。这些对你来说轻而易举，但对计算机来说却极其困难。

**没有计算机视觉的世界**：
- 工厂里的产品质检只能靠人工，效率低、容易出错
- 自动驾驶汽车无法"看到"行人和红绿灯
- 医院里的 CT 影像只能靠医生肉眼判断，容易漏诊
- 手机相册无法自动分类人脸，找照片很麻烦

### 解决方案

计算机视觉就是 **教计算机"看"世界**——让它理解图像和视频中的内容，并做出智能决策。

打个比方：

> 教计算机看世界，就像教婴儿认识猫和狗。你给婴儿看很多猫的图片，告诉他"这是猫"；看很多狗的图片，告诉他"这是狗"。看了足够多之后，婴儿就能自己区分猫和狗了。计算机视觉也是同样的道理——给计算机看大量数据，让它学会"看懂"图像。

> **一句话总结**：计算机视觉让机器拥有了"眼睛"和"大脑"，能自动理解视觉世界。

## 2 核心原理

### 概念解释

**计算机视觉（Computer Vision，简称 CV）** 是人工智能的一个分支，研究如何让计算机从图像和视频中提取有意义的信息。

简单来说，计算机视觉要解决三类问题：

| 问题类型 | 说明 | 生活例子 |
| --- | --- | --- |
| **这是什么？** | 图像分类 | 这张照片里是猫还是狗？ |
| **在哪里？** | 目标检测 | 照片里的猫在哪个位置？ |
| **是什么形状？** | 图像分割 | 把照片里的猫精确抠出来 |

### 发展简史

计算机视觉的发展可以分为几个阶段：

| 阶段 | 时间 | 关键事件 |
| --- | --- | --- |
| 萌芽期 | 1960s-1980s | 学者开始研究让机器提取图像边缘、角点等基础特征 |
| 成长期 | 1990s-2000s | 机器学习方法兴起，SVM、Haar 级联等方法出现 |
| 爆发期 | 2012-至今 | 深度学习（CNN）彻底改变了计算机视觉，准确率飞跃 |

### 技术栈概览

学计算机视觉，你需要掌握这些工具：

| 工具 | 用途 | 难度 |
| --- | --- | --- |
| **Python** | 编程语言，CV 领域的主流语言 | 入门简单 |
| **OpenCV** | 图像处理库，做基础操作的瑞士军刀 | 入门简单 |
| **NumPy** | 数值计算库，图像本质就是 NumPy 数组 | 入门简单 |
| **PyTorch / TensorFlow** | 深度学习框架，做高级视觉任务 | 需要基础 |
| **Matplotlib** | 可视化库，显示图像和结果 | 入门简单 |

## 3 应用领域

计算机视觉的应用无处不在，以下是主要领域：

### 3.1 自动驾驶

自动驾驶汽车需要实时"看懂"周围环境：
- 检测行人、车辆、交通标志
- 识别车道线、可行驶区域
- 估计前方车辆的距离

### 3.2 医学影像

帮助医生更准确地诊断疾病：
- CT/MRI 图像中的肿瘤检测
- X 光片中的肺炎识别
- 细胞图像中的异常细胞计数

### 3.3 人脸识别

从手机解锁到安防监控：
- 手机面部解锁（Face ID）
- 门禁系统的人脸验证
- 考勤系统的人脸签到

### 3.4 工业检测

工厂里的"机器质检员"：
- 产品表面缺陷检测
- 零件尺寸测量
- 装配质量检查

### 3.5 AR/VR 与娱乐

让虚拟与现实融合：
- 手机 AR 滤镜（抖音、Snapchat）
- 动作捕捉与体感游戏
- 虚拟试衣、虚拟化妆

## 4 基础用法

### 第一个计算机视觉程序预览

虽然这一章主要是概念介绍，但我们先预览一下后面会用到的代码长什么样：

```python
# 导入 OpenCV 库（后面章节会详细讲解安装）
import cv2

# 读取一张图片（就像把一张照片放到桌子上）
img = cv2.imread('cat.jpg')

# 显示图片（就像把照片拿起来看）
cv2.imshow('My First CV Program', img)

# 等待用户按键（让照片在屏幕上停留）
cv2.waitKey(0)

# 关闭窗口（看完之后把照片收起来）
cv2.destroyAllWindows()
```

> **原理**：就这么简单！计算机视觉的第一步永远是 **读取图像 → 处理图像 → 显示结果**。后面所有章节都是在这个基础上做文章。

## 6 新手常见误区

### 误区 1："计算机视觉就是图像处理"

**错！** 图像处理只是手段，不是目的。

- **图像处理**：对图像做操作（如模糊、锐化、调色），输入是图像，输出也是图像
- **计算机视觉**：从图像中提取信息，输入是图像，输出是 **理解**（比如"这是一只猫"）

打个比方：图像处理就像给照片加滤镜，计算机视觉则是看懂照片里有什么。

### 误区 2："学计算机视觉需要很强的数学基础"

不是的。虽然高级研究需要数学，但 **入门和实践不需要**。

- OpenCV 帮你封装好了所有数学运算
- 你只需要知道"调用什么函数"和"参数是什么意思"
- 等到需要深入理解原理时，再补数学也不迟

### 误区 3："必须用 C++ 才能做计算机视觉"

不是的。虽然 OpenCV 底层是 C++ 写的，但 **Python 才是现在的主流选择**：

- Python 语法简单，学习曲线平缓
- Python 的 CV 生态极其丰富（OpenCV、PyTorch、TensorFlow 都有 Python 接口）
- 工业界和学术界都用 Python 做 CV

✅ 正确做法：先用 Python + OpenCV 入门，需要高性能时再用 C++

### 误区 4："一上来就要学深度学习"

**错！** 深度学习是高级内容，基础没打好直接学深度学习会很痛苦。

正确的学习路线：
1. 先学 OpenCV 基础操作（图像读写、滤波、边缘检测）
2. 再学传统 CV 算法（轮廓检测、特征点、模板匹配）
3. 最后学深度学习（CNN、目标检测、图像分割）
