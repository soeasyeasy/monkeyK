## 1 为什么需要统计与概率？

### 痛点分析

假设你要训练一个 AI 预测房价：

- 你有 1000 套房的数据（面积、位置、价格）
- 怎么知道"典型"的房价是多少？→ 需要**平均数**
- 有没有特别贵或特别便宜的异常数据？→ 需要**中位数**
- 某区域房价超过 500 万的概率是多少？→ 需要**概率**

打个比方：

> 统计就像给数据"做体检"——告诉你数据的整体情况。
> 概率就像"天气预报"——告诉你某件事发生的可能性。

## 2 核心原理

### 2.1 数据收集与整理

```
数据分类：
  数值型：可以用数字衡量的
    例：房价 500 万、面积 120 ㎡、温度 25°C
  分类型：用类别描述的
    例：颜色（红/蓝）、城市（北京/上海）

数据整理步骤：
  1. 收集数据（如调查 1000 套房的价格）
  2. 排序（从低到高排列）
  3. 分组（按价格区间分组）
  4. 统计（计算每组的数量）
```

### 2.2 平均数、中位数、众数

```
平均数（Mean）：所有数据的总和 ÷ 数据个数
  例：5 套房价格 100, 200, 300, 400, 500 万
  平均数 = (100+200+300+400+500) ÷ 5 = 300 万

  特点：容易受极端值影响
  如果有一套 5000 万的豪宅加入：
  平均数 = (100+200+300+400+500+5000) ÷ 6 ≈ 1083 万
  → 被豪宅"拉高"了

中位数（Median）：排序后最中间的数
  例：100, 200, 300, 400, 500
  中位数 = 300（正中间）

  加入 5000 万后：100, 200, 300, 400, 500, 5000
  中位数 = (300+400) ÷ 2 = 350 万
  → 受极端值影响小！

众数（Mode）：出现次数最多的数
  例：100, 200, 200, 300, 300, 300, 400
  众数 = 300（出现了 3 次）
```

| 统计量 | 优点 | 缺点 | 适用场景 |
| --- | --- | --- | --- |
| 平均数 | 利用所有数据 | 受极端值影响大 | 数据均匀分布时 |
| 中位数 | 不受极端值影响 | 没利用所有数据 | 有极端值时（如房价）|
| 众数 | 直观 | 可能不唯一 | 分类型数据 |

> 打个比方：平均数像"大家平分蛋糕"——有人吃得多有人吃得少，但算出来每人一份。中位数像"排队站中间的人"——不管两边的人多高多矮，中间那个人就是中位数。

### 2.3 简单概率

```
概率：某件事发生的可能性大小

  P(事件) = 有利结果数 ÷ 总结果数

例 1：掷骰子
  掷出 6 的概率 = 1/6 ≈ 0.167
  掷出偶数的概率 = 3/6 = 1/2 = 0.5

例 2：AI 分类
  数据集中有 300 只猫、200 只狗
  随机拿一张图片是猫的概率 = 300/500 = 0.6 = 60%

概率的范围：
  P = 0 → 不可能发生
  P = 0.5 → 一半可能
  P = 1 → 一定发生
  0 ≤ P ≤ 1（概率永远在 0 到 1 之间）
```

### 2.4 统计图表

```
条形图：用柱子高度表示数量
  适合：比较不同类别的数量
  例：猫 300 只、狗 200 只、鸟 100 只

折线图：用折线表示变化趋势
  适合：显示数据随时间的变化
  例：训练损失随轮次的变化

饼图：用扇形面积表示占比
  适合：显示各部分占总体的比例
  例：训练集 70%、验证集 15%、测试集 15%

散点图：用点的位置表示两个变量的关系
  适合：发现变量之间的相关性
  例：面积 vs 房价
```

## 3 基础用法

```python
import numpy as np

# === 平均数 ===
prices = np.array([100, 200, 300, 400, 500])  # 5 套房的价格（万元）
mean_price = np.mean(prices)  # 求平均数
print(f"平均房价 = {mean_price} 万")  # → 300.0 万

# === 中位数 ===
prices_with_mansion = np.array([100, 200, 300, 400, 500, 5000])
median_price = np.median(prices_with_mansion)  # 求中位数
print(f"中位数房价 = {median_price} 万")  # → 350.0 万

# === 众数（用 scipy）===
from scipy import stats
data = np.array([100, 200, 200, 300, 300, 300, 400])
mode_result = stats.mode(data, keepdims=True)  # 求众数
print(f"众数 = {mode_result.mode[0]}")  # → 300

# === 概率计算 ===
cats = 300  # 猫的数量
dogs = 200  # 狗的数量
total = cats + dogs  # 总数
p_cat = cats / total  # 随机抽到猫的概率
print(f"抽到猫的概率 = {p_cat}")  # → 0.6

# === 标准差（数据的离散程度）===
prices = np.array([280, 290, 300, 310, 320])  # 价格很接近
std1 = np.std(prices)
print(f"价格标准差 = {std1:.2f}")  # → 14.14（波动小）

prices2 = np.array([100, 200, 300, 400, 500])  # 价格差距大
std2 = np.std(prices2)
print(f"价格标准差 = {std2:.2f}")  # → 141.42（波动大）
```

## 4 对比表格

| 统计量 | 公式 | 特点 | AI 中的应用 |
| --- | --- | --- | --- |
| 平均数 | Σx / n | 利用所有数据，受极端值影响 | 损失函数的平均值 |
| 中位数 | 排序后取中间 | 不受极端值影响 | 异常值检测 |
| 众数 | 出现最多的值 | 直观 | 分类任务的预测 |
| 标准差 | √(Σ(x-μ)²/n) | 衡量数据分散程度 | 数据归一化 |
| 概率 | 有利/总数 | 0 到 1 之间 | 分类的置信度 |

## 5 新手常见误区

### 误区 1："平均数一定能代表整体"

**错！** 有极端值时平均数会失真：

```python
# 5 个员工工资：5000, 5500, 6000, 6500, 7000
# 平均 = 6000，看起来合理

# 加上老板工资 100000 后：
# 平均 = 21667，大多数人都"被平均"了
# 这时候中位数更能代表"一般水平"
```

### 误区 2："概率 50% 就是两次里一定中一次"

不是的。概率是长期趋势，不是短期保证：

```python
# 掷硬币正面概率 50%
# 但不代表掷 2 次一定 1 次正面
# 可能 2 次都正面，也可能 2 次都反面
# 概率 50% 的意思是：掷很多次后，正面占比趋近 50%
```

### 误区 3："标准差越大越好"

不一定。标准差大说明数据分散，小说明数据集中：

```python
# AI 训练中，损失的标准差大 → 训练不稳定
# 希望损失稳步下降，标准差小一些更好
```

## 6 动手练习

### 练习 1：计算平均数和中位数

5 个学生的分数：72, 85, 90, 68, 95。求平均数和中位数。

<details>
<summary>点击查看答案</summary>

```python
import numpy as np
scores = np.array([72, 85, 90, 68, 95])

mean_score = np.mean(scores)  # 平均数
median_score = np.median(scores)  # 中位数

print(f"平均数 = {mean_score}")  # → 82.0
print(f"中位数 = {median_score}")  # → 85.0

# 排序后：68, 72, 85, 90, 95 → 中间是 85
```

</details>

### 练习 2：概率计算

一个袋子里有 5 个红球、3 个蓝球、2 个绿球。随机摸一个球，求摸到每种颜色球的概率。

<details>
<summary>点击查看答案</summary>

```python
red = 5    # 红球
blue = 3   # 蓝球
green = 2  # 绿球
total = red + blue + green  # 总数 10

p_red = red / total     # 红球概率
p_blue = blue / total   # 蓝球概率
p_green = green / total # 绿球概率

print(f"P(红) = {p_red}")    # → 0.5
print(f"P(蓝) = {p_blue}")   # → 0.3
print(f"P(绿) = {p_green}")  # → 0.2

# 验证：概率之和 = 1
print(f"概率之和 = {p_red + p_blue + p_green}")  # → 1.0
```

</details>

### 练习 3（挑战）：标准差的意义

两组数据 A=[10, 10, 10, 10, 10] 和 B=[2, 8, 10, 12, 18]，分别计算标准差，说明哪组数据更分散。

<details>
<summary>点击查看答案</summary>

```python
import numpy as np

A = np.array([10, 10, 10, 10, 10])
B = np.array([2, 8, 10, 12, 18])

std_A = np.std(A)  # A 的标准差
std_B = np.std(B)  # B 的标准差

print(f"A 的标准差 = {std_A}")  # → 0.0（完全没波动）
print(f"B 的标准差 = {std_B:.2f}")  # → 5.29（波动较大）

# 结论：B 组数据更分散
# 两组平均数都是 10，但 A 全部一样，B 差距很大
```

</details>

## 7 核心知识点总结

| 知识点 | 要点 |
| --- | --- |
| 数据类型 | 数值型 vs 分类型 |
| 平均数 | 总和÷个数，受极端值影响 |
| 中位数 | 排序后取中间，不受极端值影响 |
| 众数 | 出现最多的值 |
| 概率 | 0 到 1 之间，= 有利结果/总结果 |
| 标准差 | 衡量数据分散程度 |
