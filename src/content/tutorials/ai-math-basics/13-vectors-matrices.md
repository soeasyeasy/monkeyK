## 1 为什么需要向量与矩阵？

### 痛点分析

假设你要用 AI 识别手写数字：

- 一张 28×28 的图片，怎么表示成 AI 能处理的形式？→ 需要**矩阵**（28×28 的像素矩阵）
- 神经网络有 1000 个神经元，每个神经元有 784 个权重，怎么存储？→ 需要**矩阵**（1000×784 的权重矩阵）
- 前向传播时，输入数据怎么和权重计算？→ 需要**矩阵乘法**

打个比方：

> 向量就像"快递单"——记录一个物品的多个属性（重量、尺寸、地址）。
> 矩阵就像"Excel 表格"——记录多个物品的多个属性。
> 矩阵乘法就像"批量处理"——一次性计算所有物品的总分。

### 向量和矩阵在 AI 中的角色

| 数学知识 | AI 中的应用场景 |
| --- | --- |
| 向量 | 数据表示（特征向量）、词嵌入 |
| 矩阵 | 权重矩阵、输入数据、图像像素 |
| 矩阵乘法 | 神经网络前向传播 |
| 逆矩阵 | 线性方程组求解、坐标变换 |
| 行列式 | 矩阵可逆性判断、体积变换 |

## 2 核心原理

### 2.1 向量的概念与运算

```
向量：既有大小又有方向的量

  生活化理解：
    "温度 25°C" → 标量（只有大小）
    "风速 10m/s，向东" → 向量（有大小有方向）
    
    在 AI 中：
    "房价 500 万" → 标量
    "房子特征：面积 120㎡，楼层 15，房龄 5 年" → 向量 [120, 15, 5]

向量的表示：
  列向量：竖着写
    [1]
    [2]
    [3]
  
  行向量：横着写
    [1, 2, 3]

向量的基本运算：
  加法：对应位置相加
    [1, 2, 3] + [4, 5, 6] = [5, 7, 9]
    
    生活化：两个力的合成
    力 A = (1, 2)（向东 1，向北 2）
    力 B = (3, 4)（向东 3，向北 4）
    合力 = (4, 6)（向东 4，向北 6）

  数乘：每个元素乘以同一个数
    2 × [1, 2, 3] = [2, 4, 6]
    
    生活化：把向量"放大"或"缩小"

  点积（内积）：对应位置相乘再求和
    [1, 2, 3] · [4, 5, 6] = 1×4 + 2×5 + 3×6 = 4 + 10 + 18 = 32
    
    生活化：计算"相似度"
    用户 A 的喜好：[1, 0, 1]（喜欢电影和音乐，不喜欢运动）
    用户 B 的喜好：[1, 1, 0]（喜欢电影和运动，不喜欢音乐）
    点积 = 1×1 + 0×1 + 1×0 = 1（有 1 个共同爱好）

  模（长度）：向量的大小
    |[1, 2, 3]| = √(1² + 2² + 3²) = √14 ≈ 3.74
    
    生活化：向量的"长度"或"强度"
```

> 打个比方：向量就像"多维坐标"——在 3D 空间里，(x, y, z) 就是一个向量，告诉你从原点出发要走多远。

### 2.2 矩阵的基础

```
矩阵：按行列排列的数的矩形阵列

  生活化理解：
    一个班级的成绩表：
         语文  数学  英语
    张三  [90   85   88]
    李四  [78   92   80]
    王五  [85   78   90]
    
    这就是一个 3×3 的矩阵（3 行 3 列）

矩阵的表示：
  A = [a₁₁  a₁₂  a₁₃]
      [a₂₁  a₂₂  a₂₃]
      [a₃₁  a₃₂  a₃₃]
  
  aᵢⱼ 表示第 i 行第 j 列的元素

特殊矩阵：
  零矩阵：所有元素都是 0
  单位矩阵 I：对角线是 1，其他是 0
    I = [1 0 0]
        [0 1 0]
        [0 0 1]
    性质：A × I = A（类似数字中的 1）
  
  转置矩阵 Aᵀ：行列互换
    A = [1 2 3]    →    Aᵀ = [1 4]
        [4 5 6]             [2 5]
                              [3 6]

矩阵的基本运算：
  加法：对应位置相加（形状必须相同）
    [1 2] + [5 6] = [6  8]
    [3 4]   [7 8]   [10 12]

  数乘：每个元素乘以同一个数
    2 × [1 2] = [2 4]
        [3 4]   [6 8]
```

### 2.3 矩阵乘法（超重要！）

```
矩阵乘法：C = A × B

  规则：C 的第 i 行第 j 列元素 = A 的第 i 行 与 B 的第 j 列 的点积
  
  形状要求：A 是 m×n，B 必须是 n×p，结果 C 是 m×p
  （A 的列数 = B 的行数）

  计算示例：
  A = [1 2]    B = [5 6]
      [3 4]        [7 8]
  
  C = A × B = [1×5+2×7  1×6+2×8] = [19 22]
              [3×5+4×7  3×6+4×8]   [43 50]

  生活化理解：
    假设你买了两种商品，每种商品有两个属性（价格、数量）：
    商品 A：价格 1 元，数量 2 个
    商品 B：价格 3 元，数量 4 个
    
    现在有两个商店，每个商店的折扣不同：
    商店 1：价格打 5 折，数量打 6 折
    商店 2：价格打 7 折，数量打 8 折
    
    矩阵乘法可以一次性算出你在每个商店的总花费！

  AI 中的应用：
    神经网络的前向传播：
    output = input × weights + bias
    
    input: [1×784]（一张图片的 784 个像素）
    weights: [784×256]（784 个输入，256 个神经元）
    output: [1×256]（256 个神经元的输出）
    
    一次矩阵乘法，完成 784×256 = 200,704 次乘法运算！
```

> 打个比方：矩阵乘法就像"批量处理"——把多个独立的计算打包在一起，用一次操作完成，效率极高。

### 2.4 逆矩阵与行列式

```
逆矩阵：A⁻¹，满足 A × A⁻¹ = I（单位矩阵）

  生活化理解：
    数字中的倒数：2 × (1/2) = 1
    矩阵中的逆矩阵：A × A⁻¹ = I
    
    作用："撤销"矩阵变换
    如果 A 把向量旋转了 90°，A⁻¹ 就把它转回来

  存在条件：
    只有方阵（行数=列数）才可能有逆矩阵
    且行列式不为 0（det(A) ≠ 0）

行列式：det(A) 或 |A|，一个标量值

  2×2 矩阵的行列式：
    A = [a b]
        [c d]
    det(A) = ad - bc

  生活化理解：
    行列式表示矩阵变换的"缩放因子"
    det(A) = 2 → 面积变为原来的 2 倍
    det(A) = 0 → 面积变为 0（矩阵不可逆，信息丢失）
    det(A) < 0 → 方向反转（镜像变换）

  AI 中的应用：
    行列式为 0 → 矩阵不可逆 → 特征之间线性相关（多重共线性）
    需要去除冗余特征，或者用正则化
```

## 3 基础用法

```python
import numpy as np

# === 向量的创建与运算 ===
# ✅ 正确：用 numpy 数组创建向量
v1 = np.array([1, 2, 3])                # 创建一个 3 维向量
v2 = np.array([4, 5, 6])                # 创建另一个向量

# 向量加法
v_add = v1 + v2                         # 对应位置相加
print(f"v1 + v2 = {v_add}")             # → [5, 7, 9]

# 数乘
v_scale = 2 * v1                        # 每个元素乘以 2
print(f"2 × v1 = {v_scale}")            # → [2, 4, 6]

# 点积（内积）
v_dot = np.dot(v1, v2)                  # 或者 v1 @ v2
print(f"v1 · v2 = {v_dot}")             # → 32（1×4 + 2×5 + 3×6）

# 向量的模（长度）
v_norm = np.linalg.norm(v1)             # 计算向量的长度
print(f"|v1| = {v_norm:.2f}")           # → 3.74（√14）

# ❌ 错误：用列表做向量运算
# v1_list = [1, 2, 3]
# v2_list = [4, 5, 6]
# v1_list + v2_list   # → [1, 2, 3, 4, 5, 6]（列表拼接，不是向量加法！）

# === 矩阵的创建与运算 ===
# ✅ 正确：用 numpy 创建矩阵
A = np.array([[1, 2],                   # 2×2 矩阵
              [3, 4]])

B = np.array([[5, 6],
              [7, 8]])

# 矩阵加法
C_add = A + B                           # 对应位置相加
print(f"A + B =\n{C_add}")
# → [[6, 8], [10, 12]]

# 矩阵数乘
C_scale = 2 * A                         # 每个元素乘以 2
print(f"2A =\n{C_scale}")
# → [[2, 4], [6, 8]]

# 矩阵乘法（超重要！）
C_mul = A @ B                           # 或者 np.dot(A, B)
print(f"A × B =\n{C_mul}")
# → [[19, 22], [43, 50]]

# ❌ 错误：用 * 做矩阵乘法
# A * B   # → [[5, 12], [21, 32]]（这是对应位置相乘，不是矩阵乘法！）

# === 转置矩阵 ===
A_T = A.T                               # 行列互换
print(f"A 的转置 =\n{A_T}")
# → [[1, 3], [2, 4]]

# === 单位矩阵 ===
I = np.eye(3)                           # 3×3 单位矩阵
print(f"单位矩阵 =\n{I}")
# → [[1, 0, 0], [0, 1, 0], [0, 0, 1]]

# === 逆矩阵 ===
A_inv = np.linalg.inv(A)                # 计算 A 的逆矩阵
print(f"A 的逆矩阵 =\n{A_inv}")
# → [[-2, 1], [1.5, -0.5]]

# 验证：A × A⁻¹ = I
identity = A @ A_inv
print(f"A × A⁻¹ =\n{identity}")
# → [[1, 0], [0, 1]]（单位矩阵，验证成功！）

# === 行列式 ===
det_A = np.linalg.det(A)                # 计算行列式
print(f"det(A) = {det_A:.2f}")          # → -2.00

# 行列式为 0 → 矩阵不可逆
singular_matrix = np.array([[1, 2],     # 第二行是第一行的 2 倍
                             [2, 4]])
det_singular = np.linalg.det(singular_matrix)
print(f"奇异矩阵的行列式 = {det_singular:.2f}")  # → 0.00（不可逆！）

# === AI 中的应用：神经网络前向传播 ===
# 模拟一个简单的神经网络层
input_data = np.array([[1, 2, 3]])      # 输入：1 个样本，3 个特征
weights = np.array([[0.1, 0.2],         # 权重：3 个输入，2 个神经元
                    [0.3, 0.4],
                    [0.5, 0.6]])
bias = np.array([0.1, 0.2])             # 偏置：2 个神经元

# 前向传播：output = input × weights + bias
output = input_data @ weights + bias    # 矩阵乘法 + 广播
print(f"神经网络输出 = {output}")
# → [[1.6, 2.2]]（2 个神经元的输出值）
```

## 4 对比表格

| 运算 | 符号 | Python | 规则 | AI 中的应用 |
| --- | --- | --- | --- | --- |
| 向量加法 | a + b | `a + b` | 对应位置相加 | 特征融合 |
| 向量点积 | a · b | `a @ b` | 对应相乘再求和 | 相似度计算 |

## 5 新手常见误区

### 误区 1："用 * 做矩阵乘法"

Python 中 `*` 是对应位置相乘，不是矩阵乘法：

```python
import numpy as np

A = np.array([[1, 2],
              [3, 4]])
B = np.array([[5, 6],
              [7, 8]])

# ✅ 正确：用 @ 运算符或 np.dot
C = A @ B                             # 矩阵乘法
print(f"A @ B =\n{C}")
# → [[19, 22], [43, 50]]

# ❌ 错误：用 *
C_wrong = A * B                       # 对应位置相乘（Hadamard 积）
print(f"A * B =\n{C_wrong}")
# → [[5, 12], [21, 32]]（不是矩阵乘法！）
```

### 误区 2："矩阵乘法满足交换律"

矩阵乘法不满足交换律：A × B ≠ B × A

```python
import numpy as np

A = np.array([[1, 2],
              [3, 4]])
B = np.array([[5, 6],
              [7, 8]])

AB = A @ B                            # A × B
BA = B @ A                            # B × A

print(f"A @ B =\n{AB}")
# → [[19, 22], [43, 50]]

print(f"B @ A =\n{BA}")
# → [[23, 34], [31, 46]]

# AB ≠ BA！矩阵乘法顺序很重要
# 在神经网络中，层级的顺序不能随便换
```

### 误区 3："所有矩阵都有逆矩阵"

只有方阵且行列式不为 0 时才有逆矩阵：

```python
import numpy as np

# ✅ 可逆矩阵
A = np.array([[1, 2],
              [3, 4]])
A_inv = np.linalg.inv(A)              # 可以求逆
print(f"A 可逆，det = {np.linalg.det(A):.2f}")  # → -2.00

# ❌ 不可逆矩阵（奇异矩阵）
B = np.array([[1, 2],
              [2, 4]])                # 第二行是第一行的 2 倍
try:
    B_inv = np.linalg.inv(B)
except np.linalg.LinAlgError as e:
    print(f"B 不可逆：{e}")           # → Singular matrix
print(f"B 的行列式 = {np.linalg.det(B):.2f}")  # → 0.00
```

### 误区 4："向量点积和矩阵乘法一样"

点积和矩阵乘法不同：

```python
import numpy as np

v1 = np.array([1, 2, 3])              # 1D 向量
v2 = np.array([4, 5, 6])              # 1D 向量

# 向量点积：结果是标量
dot_product = np.dot(v1, v2)          # 或者 v1 @ v2
print(f"v1 · v2 = {dot_product}")     # → 32（一个数）

# 矩阵乘法：结果是矩阵
A = v1.reshape(1, 3)                  # 1×3 矩阵
B = v2.reshape(3, 1)                  # 3×1 矩阵
mat_mul = A @ B                       # 矩阵乘法
print(f"A @ B = {mat_mul}")           # → [[32]]（1×1 矩阵）

# 虽然数值相同，但类型不同：一个是标量，一个是矩阵
```

### 误区 5："形状不匹配的矩阵也能相乘"

矩阵乘法要求形状匹配：

```python
import numpy as np

A = np.array([[1, 2, 3],              # 2×3 矩阵
              [4, 5, 6]])
B = np.array([[7, 8],                 # 3×2 矩阵
              [9, 10],
              [11, 12]])

# ✅ 正确：A 的列数（3）= B 的行数（3），可以相乘
C = A @ B                             # 结果是 2×2 矩阵
print(f"A @ B 的形状: {C.shape}")     # → (2, 2)

# ❌ 错误：形状不匹配
D = np.array([[1, 2],                 # 2×2 矩阵
              [3, 4]])
# A @ D   # → ValueError！A 是 2×3，D 是 2×2，3 ≠ 2，无法相乘
```

### 练习 3（挑战）：神经网络前向传播

实现一个简单的神经网络层：输入是 2 个样本，每个样本 3 个特征；权重矩阵是 3×4（3 个输入，4 个神经元）；偏置是 4 维向量。计算输出。

<details>
<summary>点击查看答案</summary>

```python
import numpy as np

# 输入数据：2 个样本，每个样本 3 个特征
X = np.array([[1, 2, 3],              # 样本 1
              [4, 5, 6]])             # 样本 2
print(f"输入形状: {X.shape}")         # → (2, 3)

# 权重矩阵：3 个输入，4 个神经元
W = np.array([[0.1, 0.2, 0.3, 0.4],  # 第 1 个输入的权重
              [0.5, 0.6, 0.7, 0.8],  # 第 2 个输入的权重
              [0.9, 1.0, 1.1, 1.2]]) # 第 3 个输入的权重
print(f"权重形状: {W.shape}")         # → (3, 4)

# 偏置：4 个神经元
b = np.array([0.1, 0.2, 0.3, 0.4])
print(f"偏置形状: {b.shape}")         # → (4,)

# 前向传播：Z = X @ W + b
Z = X @ W + b                         # 矩阵乘法 + 广播
print(f"输出形状: {Z.shape}")         # → (2, 4)
print(f"输出:\n{Z}")
# → [[3.8, 4.4, 5.0, 5.6],
#    [8.3, 10.1, 11.9, 13.7]]

# 解释：
# 样本 1 的输出：[3.8, 4.4, 5.0, 5.6]（4 个神经元的激活值）
# 样本 2 的输出：[8.3, 10.1, 11.9, 13.7]
```

## 7 核心知识点总结

| 知识点 | 要点 |
| --- | --- |
| 向量 | 有大小有方向的量，用数组表示 |
| 向量加法 | 对应位置相加 |
| 点积 | 对应相乘再求和，衡量相似度 |
| 矩阵 | 按行列排列的数的矩形阵列 |
| 矩阵加法 | 对应位置相加，形状必须相同 |
| 矩阵乘法 | A 的列数 = B 的行数，用 @ 运算符 |
| 转置 | 行列互换 |
| 单位矩阵 | 对角线为 1，其他为 0，类似数字 1 |
| 逆矩阵 | A × A⁻¹ = I，只有方阵且 det ≠ 0 时存在 |
| 行列式 | 标量值，表示矩阵变换的缩放因子 |
