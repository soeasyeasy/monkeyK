# 第3章：比与比例——AI 中的缩放思维

## 本章导读

在学这一章之前，你可能会有这些疑问：

- "比"和"除法"有什么区别？
- 正比例和反比例到底是什么意思？
- 百分数在 AI 中哪里用得到？
- 听说 AI 有个"学习率"，跟比例有什么关系？

这一章帮你建立"比例思维"。在 AI 中，几乎所有东西都在按比例缩放——学习率、损失权重、数据归一化，都离不开比与比例。

---

## 1 为什么需要比与比例？

### 痛点分析

假设你要训练一个 AI 识别猫和狗：

- 猫的图片有 800 张，狗的图片有 200 张
- 猫和狗的比例是 800:200 = 4:1

如果不理解比例，你就不知道数据严重不平衡——AI 会偏向识别猫。

打个比方：

> 比例就像做菜时的配料比——盐放太多菜就咸了，糖放太多就甜了。AI 训练也一样，各种数据要按比例来。

### 比例在 AI 中的角色

| 比例知识 | AI 中的应用 |
| --- | --- |
| 比 | 数据集的正负样本比例 |
| 正比例 | 损失越大，梯度越大 |
| 反比例 | 学习率越小，训练越慢但越稳 |
| 百分数 | 准确率 95%、召回率 80% |
| 归一化 | 把数据缩放到 0-1 之间 |

## 2 核心原理

### 2.1 比的意义

```
比：两个数相除的关系

  a : b = a ÷ b

例：
  3 : 5 = 3 ÷ 5 = 0.6
  读作"3 比 5"

比的化简：
  800 : 200
  = 800÷200 : 200÷200    （两边同除以 200）
  = 4 : 1
```

### 2.2 正比例

```
正比例：一个量增大，另一个也按相同比例增大

  y = k × x （k 是常数）

例：买苹果，单价 5 元/斤
  买 1 斤 → 5 元
  买 2 斤 → 10 元
  买 3 斤 → 15 元
  总价 = 5 × 斤数（正比例关系）

在 AI 中：
  损失值 = k × 误差（误差越大，损失越大——正比例）
```

### 2.3 反比例

```
反比例：一个量增大，另一个按反比缩小

  y = k ÷ x （k 是常数）

例：跑 100 米
  速度 5 m/s → 时间 20 秒
  速度 10 m/s → 时间 10 秒
  速度 20 m/s → 时间 5 秒
  时间 = 100 ÷ 速度（反比例关系）

在 AI 中：
  训练轮数 ≈ k ÷ 学习率（学习率越大，需要的轮数越少——反比例）
```

### 2.4 百分数

```
百分数：分母为 100 的分数

  75% = 75/100 = 0.75

百分数 ↔ 小数：
  小数 → 百分数：乘以 100，加 %
    0.85 → 85%
  百分数 → 小数：去掉 %，除以 100
    60% → 0.6

AI 中的百分数：
  准确率 = 95%  →  0.95
  损失下降 = 30%  →  0.3
```

### 2.5 归一化（超重要！）

```
归一化：把数据缩放到 0 到 1 之间

公式：x_normalized = (x - min) / (max - min)

例：把 [20, 40, 60, 80, 100] 归一化
  min = 20, max = 100
  20 → (20-20)/(100-20) = 0/80 = 0
  40 → (40-20)/(100-20) = 20/80 = 0.25
  60 → (60-20)/(100-20) = 40/80 = 0.5
  80 → (80-20)/(100-20) = 60/80 = 0.75
  100 → (100-20)/(100-20) = 80/80 = 1.0

为什么 AI 需要归一化？
  如果有的特征是年龄（0-100），有的特征是收入（0-1000000）
  收入会完全"压过"年龄，AI 学不到年龄的作用
  归一化后，所有特征都在 0-1 之间，公平竞争
```

> 打个比方：归一化就像考试评分——语文满分 150，数学满分 150，英语满分 150。如果直接用原始分数，各科满分不同没法比。归一化就是把所有分数都换算成百分制。

## 3 基础用法

```python
# === 比的计算 ===
cats = 800  # 猫的图片数
dogs = 200  # 狗的图片数
ratio = cats / dogs  # 猫狗比
print(f"猫狗比 = {ratio}")  # → 4.0（猫是狗的 4 倍）

# === 百分数计算 ===
total = 200   # 总共 200 张图片
correct = 180 # 预测正确 180 张
accuracy = correct / total * 100  # 准确率
print(f"准确率 = {accuracy}%")  # → 90.0%

# === 归一化 ===
import numpy as np
data = np.array([20, 40, 60, 80, 100])  # 原始数据

# 归一化公式
data_min = data.min()   # 最小值 → 20
data_max = data.max()   # 最大值 → 100
data_normalized = (data - data_min) / (data_max - data_min)  # 归一化
print(f"归一化后：{data_normalized}")
# → [0.    0.25  0.5   0.75  1.  ]

# === 正比例验证 ===
x = np.array([1, 2, 3, 4, 5])  # 输入
k = 3  # 比例常数
y = k * x  # 正比例关系
print(f"y = {k} × x = {y}")  # → [3 6 9 12 15]

# === 反比例验证 ===
x = np.array([1, 2, 4, 5, 10])  # 输入
k = 20  # 比例常数
y = k / x  # 反比例关系
print(f"y = {k} ÷ x = {y}")  # → [20. 10. 5. 4. 2.]
```

## 4 对比表格

| 概念 | 公式 | 图像特征 | AI 中的例子 |
| --- | --- | --- | --- |
| 正比例 | y = kx | 过原点的直线 | 损失与误差 |
| 反比例 | y = k/x | 双曲线 | 训练轮数与学习率 |
| 百分数 | x% = x/100 | - | 准确率、召回率 |
| 归一化 | (x-min)/(max-min) | 缩放到 [0,1] | 特征标准化 |

## 5 新手常见误区

### 误区 1："学习率越大越好"

**错！** 学习率和训练效果是反比例关系：

```python
# ❌ 错误：学习率太大
learning_rate = 100  # 步子太大，会"跨过"最优解

# ✅ 正确：学习率要适中
learning_rate = 0.001  # 小步走，稳定收敛
```

### 误区 2："归一化就是除以最大值"

不完全是。标准归一化要减去最小值：

```python
# ❌ 错误：只除以最大值
x_norm = x / x.max()  # 最小值不会变成 0

# ✅ 正确：先减最小值，再除以范围
x_norm = (x - x.min()) / (x.max() - x.min())  # 结果在 [0, 1]
```

### 误区 3："比例就是除法"

比和除法相关但有区别：

```python
# 比强调的是两个量的关系
# 3:5 表示 3 和 5 的关系，不一定要算出结果

# 除法是一种运算
# 3 ÷ 5 = 0.6 是一个计算过程
```

## 6 动手练习

### 练习 1：化简比

一个数据集中有 600 张训练图片和 400 张测试图片，化简训练集与测试集的比例。

<details>
<summary>点击查看答案</summary>

```python
train = 600
test = 400

# 求最大公约数
import math
gcd = math.gcd(train, test)  # → 200

# 化简比
ratio_train = train // gcd  # → 3
ratio_test = test // gcd    # → 2
print(f"训练集:测试集 = {ratio_train}:{ratio_test}")  # → 3:2
```

</details>

### 练习 2：归一化

将以下数据归一化到 [0, 1]：[10, 30, 50, 70, 90]

<details>
<summary>点击查看答案</summary>

```python
import numpy as np
data = np.array([10, 30, 50, 70, 90])

data_min = data.min()  # → 10
data_max = data.max()  # → 90
data_norm = (data - data_min) / (data_max - data_min)
print(f"归一化：{data_norm}")
# → [0.   0.25 0.5  0.75 1.  ]
```

</details>

### 练习 3（挑战）：准确率计算

一个 AI 模型测试了 500 张图片，其中 425 张预测正确。求准确率（百分数和小数各是多少）。

<details>
<summary>点击查看答案</summary>

```python
total = 500
correct = 425

# 小数形式
accuracy_decimal = correct / total
print(f"准确率（小数）= {accuracy_decimal}")  # → 0.85

# 百分数形式
accuracy_percent = accuracy_decimal * 100
print(f"准确率（百分数）= {accuracy_percent}%")  # → 85.0%
```

</details>

## 7 核心知识点总结

| 知识点 | 要点 |
| --- | --- |
| 比 | 两个量的关系，可以化简 |
| 正比例 | y = kx，同增同减 |
| 反比例 | y = k/x，此增彼减 |
| 百分数 | 分母为 100 的分数，AI 指标常用 |
| 归一化 | 把数据缩放到 [0,1]，消除量纲差异 |
