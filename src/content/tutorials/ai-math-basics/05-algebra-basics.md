# 第5章：代数基础——从算术到代数

## 本章导读

进入初中篇，我们终于要从"具体数字"走向"抽象符号"了。在学这一章之前，你可能会有这些疑问：

- 算术已经够用了，为什么还要用字母代替数字？
- 代数式看起来像天书，到底在表达什么？
- 整式加减、因式分解，跟 AI 有什么关系？
- 我代码写得挺溜，数学符号一多就头大，怎么办？

别担心，这一章我们会把"字母表示数"这件事讲透。你会发现：代数其实就是"更高级的算术"，而 AI 模型里那些看起来很吓人的公式，本质上就是一个个代数式。

## 1 为什么需要代数？

### 痛点分析

假设你是一个 AI 程序员，老板让你写一个"根据面积算房价"的程序：

- 用算术：100 平米 × 5 万/平米 = 500 万，120 平米 × 5 万/平米 = 600 万……
- 每来一个新面积，你就要重写一遍算式——累不累？
- 如果单价不是 5 万，而是根据地段变化呢？你要写多少个算式？

打个比方：

> 算术就像"照着菜谱做菜"——每次换食材都要重新写步骤。
> 代数就像"发明一个通用菜谱模板"——不管什么食材，套进去就能用。

### 代码对比：算术 vs 代数

```python
# ❌ 纯算术写法：每套房都要写一遍
price1 = 100 * 5  # 100 平米，单价 5 万
price2 = 120 * 5  # 120 平米，单价 5 万
price3 = 80  * 5  # 80 平米，单价 5 万
# 来第 100 套房？继续写……

# ✅ 代数写法：一个公式搞定所有房
def price(area, unit_price=5):  # area 是面积，unit_price 是单价
    return area * unit_price    # 一个公式，通用！

print(price(100))   # → 500
print(price(120))   # → 600
print(price(80))    # → 400
```

### 代数在 AI 中的角色

| 代数知识 | AI 中的应用场景 |
| --- | --- |
| 用字母表示数 | 模型参数（权重 w、偏置 b）|
| 代数式 | 损失函数、激活函数表达式 |
| 整式加减 | 梯度计算、参数更新 |
| 因式分解 | 化简复杂公式、优化计算 |

## 2 核心原理

### 2.1 用字母表示数

在算术中，我们只跟具体数字打交道：`3 + 5 = 8`。
在代数中，我们引入字母来代表"可以变化的数"或"还不知道的数"。

```
字母的两种身份：
  1. 变量：可以取不同的值
     例：房价 = 面积 × 单价，写成  P = S × p
     这里 S、p 都是变量，不同房子取值不同

  2. 未知数：某个确定的值，只是我们暂时不知道
     例：3 + x = 10，x 就是未知数，x = 7
```

> 打个比方：字母就像一个"盒子"，里面可以装不同的数字。变量是"透明盒子"，你能看到它换内容；未知数是"密封盒子"，里面有个确定的值等你去猜。

### 2.2 代数式

把数和字母用加减乘除连接起来的式子，叫代数式。

```
代数式的例子：
  3x + 5         # 读作"3x 加 5"
  2a² - 3ab + 1  # 读作"2a 平方减 3ab 加 1"
  (x + y) / 2    # 读作"x 加 y 的和除以 2"

注意：
  ✅ 2 × a 写成 2a（省略乘号）
  ✅ a × b 写成 ab
  ❌ a + b 不能写成 ab（加号不能省！）
  ❌ 2a 表示 2×a，不是 a 的 2 次方（那是 a²）
```

### 2.3 整式：单项式与多项式

```
单项式：数字和字母的乘积（没有加减号）
  例：3x,  -2a²b,  7
  系数：数字部分（3、-2、7）
  次数：所有字母指数之和（3x 是 1 次，-2a²b 是 3 次）

多项式：几个单项式的和
  例：3x² + 2x - 5
  项：3x²、2x、-5（注意符号！）
  次数：最高次项的次数（这里是 2 次）
```

| 式子 | 类型 | 系数 | 次数 |
| --- | --- | --- | --- |
| 5x | 单项式 | 5 | 1 |
| -3a²b | 单项式 | -3 | 3 |
| 2x² + 3x - 1 | 多项式 | — | 2 |
| 7 | 单项式 | 7 | 0 |

### 2.4 整式的加减

核心原则：**同类项才能合并**。同类项就是字母部分完全一样的项。

```
例 1：3x + 5x = 8x          ✅ 同类项，合并
例 2：3x + 5y 不能合并       ❌ 字母不同
例 3：2x² + 3x² = 5x²       ✅ 同类项
例 4：2x² + 3x 不能合并      ❌ 次数不同

完整例子：
  (3x² + 2x - 5) + (x² - 4x + 7)
  = 3x² + x² + 2x - 4x - 5 + 7    ← 去括号，找同类项
  = 4x² - 2x + 2                  ← 合并
```

> 打个比方：合并同类项就像"整理房间"——衣服和衣服放一起，书和书放一起，不能把衣服塞到书架上。

### 2.5 因式分解基础

因式分解是"展开的逆运算"——把一个多项式写成几个整式的乘积。

```
展开：(x + 1)(x + 2) = x² + 3x + 2    ← 从乘积到和
因式分解：x² + 3x + 2 = (x + 1)(x + 2) ← 从和到乘积

常用方法 1：提公因式
  例：2x² + 4x = 2x(x + 2)
  步骤：找最大公因式 2x，提出来

常用方法 2：公式法（平方差）
  a² - b² = (a + b)(a - b)
  例：x² - 9 = x² - 3² = (x + 3)(x - 3)

常用方法 3：公式法（完全平方）
  a² + 2ab + b² = (a + b)²
  例：x² + 6x + 9 = (x + 3)²
```

| 方向 | 名称 | 例子 |
| --- | --- | --- |
| 乘积 → 和 | 展开 | (x+1)(x+2) = x²+3x+2 |
| 和 → 乘积 | 因式分解 | x²+3x+2 = (x+1)(x+2) |

## 3 基础用法

```python
# === 用 Python 演示代数式求值 ===
# 例 1：代数式 3x + 5，当 x = 2 时等于多少？
x = 2                    # 给变量赋值
result = 3 * x + 5       # 代入计算
print(f"当 x=2 时，3x+5 = {result}")  # → 11

# ✅ 正确写法：用变量表达通用公式
def algebraic(x):        # 定义一个代数式函数
    return 3 * x + 5     # 返回 3x + 5 的结果

print(algebraic(2))      # → 11
print(algebraic(0))      # → 5
print(algebraic(-1))     # → 2

# ❌ 错误写法：把数字写死
print(3 * 2 + 5)         # 只能算 x=2 的情况，不通用
print(3 * 3 + 5)         # 只能算 x=3 的情况
# 每换一个 x 就要重写代码，这就是"算术思维"的局限

# === 整式加减演示 ===
# 计算 (3x² + 2x - 5) + (x² - 4x + 7)，用 x=2 验证
x = 2
poly1 = 3 * x**2 + 2 * x - 5    # 第一个多项式在 x=2 时的值
poly2 = x**2 - 4 * x + 7        # 第二个多项式在 x=2 时的值
sum_poly = poly1 + poly2         # 相加
print(f"两个多项式相加 = {sum_poly}")  # → 14 + 3 = 17

# 合并后的多项式：4x² - 2x + 2
simplified = 4 * x**2 - 2 * x + 2
print(f"合并后多项式 = {simplified}")  # → 17（结果一致 ✅）

# === 因式分解验证：x² - 9 = (x+3)(x-3) ===
x = 5
left = x**2 - 9                    # 左边
right = (x + 3) * (x - 3)          # 右边
print(f"左边 = {left}, 右边 = {right}")  # → 16, 16 ✅
```

## 5 新手常见误区

### 误区 1："字母就是未知的具体数字"

**错！** 字母可以是变量（取不同值），也可以是未知数（某个确定值），还可以是常数（如 π、e）。

```python
# 字母的三种身份
x = 2           # 这里 x 是一个变量
# 在 y = 2x + 1 中，x 是变量，可以取任意值

# 在方程 3x + 1 = 10 中，x 是未知数，只有 x=3 这一个解

# 在 f(x) = πx² 中，π 是字母但代表常数 3.14159...
```

### 误区 2："2a 表示 2 加 a"

**错！** 字母和数字并在一起表示乘法，不是加法。

```python
# ❌ 错误理解
# 2a = 2 + a   ← 大错特错

# ✅ 正确理解
# 2a = 2 × a
a = 3
print(2 * a)    # → 6，不是 5
```

### 误区 3："x² + x 可以合并成 x³"

**错！** 只有同类项才能合并，x² 和 x 不是同类项。

```python
# ❌ 错误合并
# x² + x = x³   ← 错！

# ✅ 正确做法：不能合并，保持原样
# x² + x 就是 x² + x
x = 2
print(x**2 + x)   # → 6
print(x**3)       # → 8（完全不一样！）
```

### 误区 4："因式分解就是展开"

**错！** 因式分解和展开是相反的过程。

```python
# 展开：(x+1)(x+2) → x² + 3x + 2   （乘积变和）
# 因式分解：x² + 3x + 2 → (x+1)(x+2) （和变乘积）

# 验证
x = 3
print((x+1)*(x+2))       # → 20（展开计算）
print(x**2 + 3*x + 2)    # → 20（结果一致）
```

### 误区 5："代数对编程没用，我有 Python 就够了"

**错！** 看不懂代数，就看不懂 AI 论文里的公式，调参只能靠猜。

```python
# 一个典型的 AI 损失函数：
# L(w, b) = (1/n) * Σ(w·xᵢ + b - yᵢ)²
# 看不懂代数，你连这个公式都读不下去
# 看懂了代数，你就知道：这是在算"预测值 vs 真实值"的平方误差平均
```

## 6 动手练习

### 练习 1：代数式求值

已知代数式 `2x² - 3x + 1`，分别计算 x = 0, 1, -1, 2 时的值。

<details>
<summary>点击查看答案</summary>

```python
def f(x):                    # 定义代数式函数
    return 2 * x**2 - 3 * x + 1

# 代入不同的 x 值
print(f"f(0)  = {f(0)}")     # → 1
print(f"f(1)  = {f(1)}")     # → 0
print(f"f(-1) = {f(-1)}")    # → 6
print(f"f(2)  = {f(2)}")     # → 3

# 提示：代入负数时记得加括号，(-1)**2 才正确
```

</details>

### 练习 2：整式加减

化简 `(5x² + 3x - 2) - (2x² - x + 4)`，并用 x = 2 验证结果。

<details>
<summary>点击查看答案</summary>

```python
# 手动化简：
# (5x² + 3x - 2) - (2x² - x + 4)
# = 5x² + 3x - 2 - 2x² + x - 4     ← 去括号，注意第二组要变号
# = (5-2)x² + (3+1)x + (-2-4)
# = 3x² + 4x - 6

# 用代码验证
x = 2
poly1 = 5 * x**2 + 3 * x - 2        # 第一个多项式
poly2 = 2 * x**2 - x + 4            # 第二个多项式
diff = poly1 - poly2                 # 相减
print(f"原式在 x=2 时 = {diff}")     # → 14

simplified = 3 * x**2 + 4 * x - 6   # 化简后的多项式
print(f"化简后在 x=2 时 = {simplified}")  # → 14 ✅ 一致
```

</details>

### 练习 3（挑战）：因式分解验证

用 Python 验证 `x² - 5x + 6 = (x - 2)(x - 3)`，分别取 x = 0, 1, 4, 10 验证。

<details>
<summary>点击查看答案</summary>

```python
# 验证因式分解：x² - 5x + 6 = (x-2)(x-3)
test_values = [0, 1, 4, 10]         # 测试多个 x 值

for x in test_values:
    left = x**2 - 5 * x + 6         # 左边：原多项式
    right = (x - 2) * (x - 3)       # 右边：因式分解形式
    print(f"x={x:2d}: 左边={left:3d}, 右边={right:3d}, 相等={left == right}")

# 输出：
# x= 0: 左边=  6, 右边=  6, 相等=True
# x= 1: 左边=  2, 右边=  2, 相等=True
# x= 4: 左边=  2, 右边=  2, 相等=True
# x=10: 左边= 56, 右边= 56, 相等=True  ✅

# 结论：对所有 x 都成立，因式分解正确
```

</details>

## 7 核心知识点总结

| 知识点 | 要点 |
| --- | --- |
| 用字母表示数 | 变量、未知数、常数三种身份 |
| 代数式 | 数和字母用加减乘除连接，省略乘号 |
| 单项式 | 数与字母的乘积，注意系数和次数 |
| 多项式 | 几个单项式的和，次数看最高次项 |
| 整式加减 | 只有同类项才能合并 |
| 因式分解 | 展开的逆运算，提公因式、公式法 |
