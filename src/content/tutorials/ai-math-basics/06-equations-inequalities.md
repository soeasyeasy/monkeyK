# 第6章：方程与不等式——AI 优化的数学语言

## 本章导读

上一章我们学会了"用字母表示数"，这一章我们要让字母真正"干活"——解方程、解不等式。在学这一章之前，你可能会有这些疑问：

- 我编程时从来不用解方程啊？

其实，AI 的核心任务之一就是"解方程"——训练模型的过程，本质上就是在解一个超大的方程组。而"不等式"则决定了模型的边界和约束。这一章，我们带你重新认识方程与不等式。

## 1 为什么需要方程与不等式？

### 痛点分析

假设你是一个 AI 工程师，老板让你做一个"根据房屋面积预测价格"的模型：

- 你收集了数据：面积 50㎡ 卖 250 万，100㎡ 卖 500 万，150㎡ 卖 750 万……
- 你猜测价格和面积是线性关系：`价格 = w × 面积 + b`
- 但是 w（单价）和 b（基础价）是多少？你并不知道
- 怎么从数据中反推出 w 和 b？→ 这就是**解方程**！

再比如：

- 你想让模型的误差小于 5%，怎么表达？→ `误差 < 0.05`，这就是**不等式**
- 你想让预测价格不能为负数，怎么约束？→ `价格 ≥ 0`，也是不等式

打个比方：

> 方程就像"破案"——已知结果，反推原因。
> 不等式就像"画圈"——限定一个范围，告诉你"不能出界"。

### 代码对比：没有方程 vs 用方程

```python
# ❌ 没有方程思维：暴力枚举
for w in range(1, 100):           # 从 1 试到 100
    for b in range(-1000, 1000):  # 基础价也从 -1000 试到 1000
        if w * 50 + b == 250:     # 看哪个组合满足条件
            print(f"找到了：w={w}, b={b}")
# 慢！而且只能处理整数，不精确

# ✅ 用方程思维：直接求解
# 已知：50w + b = 250 和 100w + b = 500
# 两式相减：50w = 250 → w = 5
# 代入第一式：50×5 + b = 250 → b = 0
w = 5   # 单价 5 万/㎡
b = 0   # 基础价 0
print(f"模型：价格 = {w} × 面积 + {b}")  # 一步到位！
```

### 方程在 AI 中的角色

| 方程/不等式类型 | AI 中的应用场景 |
| --- | --- |
| 一元一次方程 | 简单线性回归、学习率计算 |
| 二元一次方程组 | 多特征线性回归、双变量优化 |
| 一元二次方程 | 损失函数最小值、二次规划 |
| 不等式 | 约束条件、激活函数阈值、概率范围 |

## 2 核心原理

### 2.1 一元一次方程

只含一个未知数，且未知数的最高次数是 1 的方程。

```
标准形式：ax + b = 0（a ≠ 0）
解法：移项 → 合并 → 系数化为 1

例 1：3x + 6 = 0
  移项：3x = -6
  系数化为 1：x = -2

例 2：2(x - 3) = 5x + 3
  展开：2x - 6 = 5x + 3
  移项：2x - 5x = 3 + 6
  合并：-3x = 9
  系数化为 1：x = -3
```

> 打个比方：解方程就像"天平平衡"——左边做什么操作，右边也要做同样的操作，直到 x 单独站在一边。

### 2.2 二元一次方程组

含有两个未知数，每个未知数的最高次数是 1，由两个方程组成。

```
标准形式：
  a₁x + b₁y = c₁
  a₂x + b₂y = c₂

解法 1：代入消元法
  例：
    x + y = 10    ①
    2x - y = 5    ②
  由 ① 得：y = 10 - x    ③
  把 ③ 代入 ②：2x - (10 - x) = 5
  解得：3x = 15 → x = 5
  代回 ③：y = 10 - 5 = 5
  所以 x = 5, y = 5

解法 2：加减消元法
  同样的例子：
    x + y = 10    ①
    2x - y = 5    ②
  ① + ②：3x = 15 → x = 5（y 被消掉了！）
  代入 ①：5 + y = 10 → y = 5
```

| 解法 | 思路 | 适用场景 |
| --- | --- | --- |
| 代入消元 | 用一个方程表示 y，代入另一个 | 某个未知数系数为 1 |
| 加减消元 | 两个方程相加/减消去一个未知数 | 某个未知数系数相同或相反 |

### 2.3 一元二次方程

含有一个未知数，且最高次数是 2 的方程。

```
标准形式：ax² + bx + c = 0（a ≠ 0）

求根公式：
         -b ± √(b² - 4ac)
  x = ─────────────────────
              2a

判别式 Δ = b² - 4ac：
  Δ > 0 → 两个不相等的实数根
  Δ = 0 → 两个相等的实数根（一个根）
  Δ < 0 → 没有实数根

例：x² - 5x + 6 = 0
  a=1, b=-5, c=6
  Δ = 25 - 24 = 1 > 0 → 两个根
  x = (5 ± 1) / 2
  x₁ = 3, x₂ = 2
```

> 打个比方：判别式 Δ 就像"体检报告"——告诉你方程有几个"实数解"这个"健康指标"。

### 2.4 不等式

用 >、<、≥、≤、≠ 连接的式子，表示"不相等"的关系。

```
不等式的基本性质：
  1. 两边同加/减同一个数，不等号方向不变
     例：x + 3 > 5 → x > 2
  2. 两边同乘/除同一个正数，不等号方向不变
     例：2x < 6 → x < 3
  3. 两边同乘/除同一个负数，不等号方向反转！
     例：-2x < 6 → x > -3  ← 注意方向变了！

例：解不等式 3x - 6 ≥ 0
  移项：3x ≥ 6
  系数化为 1：x ≥ 2
  解集：[2, +∞)
```

| 性质 | 操作 | 不等号变化 |
| --- | --- | --- |
| 加减同数 | 两边加/减 c | 不变 |
| 乘除正数 | 两边乘/除正数 c | 不变 |
| 乘除负数 | 两边乘/除负数 c | **反转** |

## 3 基础用法

```python
import numpy as np

# === 一元一次方程：ax + b = 0 ===
# 解：x = -b / a
a, b = 3, -9                  # 方程 3x - 9 = 0
x = -b / a                    # 求解公式
print(f"方程 {a}x + ({b}) = 0 的解：x = {x}")  # → x = 3.0

# === 二元一次方程组 ===
# x + y = 10
# 2x - y = 5
# 用 numpy 的线性代数求解
A = np.array([[1, 1],         # 第一个方程的系数 [x的系数, y的系数]
              [2, -1]])       # 第二个方程的系数
B = np.array([10, 5])         # 等号右边的常数
solution = np.linalg.solve(A, B)  # 解方程组
print(f"x = {solution[0]}, y = {solution[1]}")  # → x = 5, y = 5

# ✅ 正确做法：用 np.linalg.solve 解线性方程组
# ❌ 错误做法：自己写循环暴力枚举（慢且不精确）

# === 一元二次方程：ax² + bx + c = 0 ===
a, b, c = 1, -5, 6            # 方程 x² - 5x + 6 = 0
delta = b**2 - 4 * a * c      # 计算判别式 Δ
print(f"判别式 Δ = {delta}")   # → 1

if delta > 0:                  # 两个不等实根
    x1 = (-b + np.sqrt(delta)) / (2 * a)
    x2 = (-b - np.sqrt(delta)) / (2 * a)
    print(f"两个根：x₁ = {x1}, x₂ = {x2}")  # → x₁ = 3, x₂ = 2
elif delta == 0:               # 两个相等实根
    x = -b / (2 * a)
    print(f"一个根：x = {x}")
else:                          # 无实根
    print("无实数根")

# === 不等式求解示例 ===
# 解不等式 3x - 6 ≥ 0
# 3x ≥ 6 → x ≥ 2
# 用 Python 验证几个值
for x in [1, 2, 3, 4]:        # 测试不同的 x
    result = 3 * x - 6        # 计算左边
    print(f"x={x}: 3x-6={result}, 满足≥0? {result >= 0}")
# x=1: -3, False
# x=2:  0, True  ← 临界点
# x=3:  3, True
# x=4:  6, True
```

## 5 新手常见误区

### 误区 1："方程两边可以随便除以未知数"

**错！** 除以含未知数的表达式可能丢解。

```python
# ❌ 错误做法
# x² = 3x
# 两边除以 x → x = 3  ← 丢掉了 x = 0 这个解！

# ✅ 正确做法：移项因式分解
# x² - 3x = 0
# x(x - 3) = 0
# 所以 x = 0 或 x = 3
x_vals = [0, 3]
for x in x_vals:
    print(f"x={x}: x²={x**2}, 3x={3*x}, 相等={x**2 == 3*x}")
# 两个解都满足 ✅
```

### 误区 2："不等式两边乘负数，方向不变"

**错！** 乘负数必须反转不等号。

```python
# ❌ 错误做法
# -2x < 6
# x < -3   ← 忘记反转！

# ✅ 正确做法
# -2x < 6
# x > -3   ← 除以 -2，方向反转！

# 验证
x = 0                        # 0 > -3，应该满足
print(f"-2×{0} = {-2*0}, < 6? {-2*0 < 6}")  # → True ✅

x = -4                       # -4 不大于 -3，不应该满足
print(f"-2×{-4} = {-2*(-4)}, < 6? {-2*(-4) < 6}")  # → False ✅
```

### 误区 3："一元二次方程一定有两个根"

**错！** 要看判别式 Δ。

```python
# Δ > 0：两个根
# x² - 5x + 6 = 0 → Δ = 1 → x₁=3, x₂=2

# Δ = 0：一个根
# x² - 2x + 1 = 0 → Δ = 0 → x = 1

# Δ < 0：无实根
# x² + x + 1 = 0 → Δ = -3 → 无实数根

for a, b, c in [(1,-5,6), (1,-2,1), (1,1,1)]:
    delta = b**2 - 4*a*c
    print(f"x² {'+' if b>0 else '-'} {abs(b)}x {'+' if c>0 else '-'} {abs(c)} = 0, Δ={delta}, 根数={'2' if delta>0 else '1' if delta==0 else '0(复数)'}")
```

### 误区 4："AI 不用解方程，梯度下降直接优化就行"

**不完全对！** 梯度下降是数值方法，但很多场景需要解析解：

```python
# 简单线性回归 y = wx + b 的最优解可以直接用方程求出：
# w = Σ(xᵢ - x̄)(yᵢ - ȳ) / Σ(xᵢ - x̄)²
# 这本质上就是解方程得到的解析解
# 比梯度下降更快、更精确！

# 数据点
x = np.array([1, 2, 3, 4, 5])
y = np.array([2, 4, 5, 4, 5])

# 解析解（解方程得到）
x_mean = np.mean(x)
y_mean = np.mean(y)
w = np.sum((x - x_mean) * (y - y_mean)) / np.sum((x - x_mean)**2)
b = y_mean - w * x_mean
print(f"解析解：w={w:.2f}, b={b:.2f}")  # → w=0.60, b=2.60
```

### 练习 2：二元一次方程组

用 numpy 解方程组：
```
3x + 2y = 12
x - y = 1
```

<details>
<summary>点击查看答案</summary>

```python
import numpy as np

# 系数矩阵
A = np.array([[3, 2],         # 3x + 2y = 12
              [1, -1]])       # x - y = 1
# 常数向量
B = np.array([12, 1])

# 求解
solution = np.linalg.solve(A, B)
x, y = solution[0], solution[1]
print(f"x = {x}, y = {y}")    # → x = 2.8, y = 1.8

# 验证
print(f"方程1: 3×{x} + 2×{y} = {3*x + 2*y}")  # → 12.0 ✅
print(f"方程2: {x} - {y} = {x - y}")           # → 1.0 ✅
```

### 练习 3（挑战）：一元二次方程的应用

一个 AI 模型的损失函数为 `L(t) = t² - 4t + 5`（t 是训练轮次），求损失最小的训练轮次。

<details>
<summary>点击查看答案</summary>

```python
# 思路：二次函数 y = ax² + bx + c 在 x = -b/(2a) 时取最小值
# L(t) = t² - 4t + 5，a=1, b=-4, c=5
a, b, c = 1, -4, 5

# 最小值点
t_min = -b / (2 * a)        # t = 4/2 = 2
L_min = a * t_min**2 + b * t_min + c  # 代入求最小值

print(f"最佳训练轮次 t = {t_min}")      # → 2.0
print(f"最小损失 L = {L_min}")          # → 1.0

# 验证：附近的 t 值损失都更大
for t in [1, 2, 3]:
    print(f"t={t}: L={t**2 - 4*t + 5}")
# t=1: L=2, t=2: L=1, t=3: L=2  ✅ t=2 确实最小
```

</details>
