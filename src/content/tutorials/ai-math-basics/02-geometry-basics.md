## 1 为什么需要几何基础？

### 痛点分析

AI 的很多应用都和几何有关：

- 图像识别：图片就是二维平面上的像素矩阵
- 自动驾驶：需要计算车辆与障碍物的距离
- 机器人：需要理解三维空间

打个比方：

> 几何就像 AI 的"眼睛"——没有几何基础，AI 就看不懂这个世界。

### 几何在 AI 中的角色

| 几何知识 | AI 中的应用 |
| --- | --- |
| 坐标系 | 图像中每个像素都有 (x, y) 坐标 |
| 距离公式 | KNN 算法计算样本间的距离 |
| 面积/体积 | 计算特征空间的区域大小 |
| 图形变换 | 图像增强（旋转、缩放、翻转）|

## 2 核心原理

### 2.1 基本图形

```
点的表示：(x, y)
  例：A(3, 4) 表示在坐标系中 x=3, y=4 的位置

线段：连接两个点的直线段
  长度 = √((x₂-x₁)² + (y₂-y₁)²)   ← 勾股定理！

三角形：三个顶点围成的图形
  面积 = 底 × 高 ÷ 2

矩形：四个直角
  面积 = 长 × 宽

圆：到定点距离相等的所有点
  面积 = π × r²
  周长 = 2 × π × r
```

### 2.2 坐标系

```
    y
    ↑
  4 |     · A(3,4)
  3 |
  2 |
  1 |
  0 +---+---+---+---→ x
      1   2   3   4

坐标系就像地图上的网格：
- x 轴：水平方向（左右）
- y 轴：垂直方向（上下）
- 原点 (0,0)：两条轴的交叉点
```

> 打个比方：坐标系就像棋盘——每个棋子都有明确的位置 (x, y)。AI 处理图片时，图片中的每个像素也都有坐标。

### 2.3 距离公式

两点之间的距离（勾股定理的应用）：

```
A(x₁, y₁) 和 B(x₂, y₂) 之间的距离：

d = √((x₂ - x₁)² + (y₂ - y₁)²)

例：A(1, 2) 和 B(4, 6) 的距离
d = √((4-1)² + (6-2)²)
  = √(9 + 16)
  = √25
  = 5
```

### 2.4 面积与体积

| 图形 | 面积公式 | 说明 |
| --- | --- | --- |
| 正方形 | a² | a 是边长 |
| 矩形 | a × b | a、b 是长和宽 |
| 三角形 | ½ × 底 × 高 | |
| 圆 | π × r² | r 是半径 |
| 梯形 | ½ × (上底+下底) × 高 | |

| 立体 | 体积公式 | 说明 |
| --- | --- | --- |
| 正方体 | a³ | a 是边长 |
| 长方体 | a × b × c | |
| 圆柱 | π × r² × h | r 是底面半径，h 是高 |
| 球 | (4/3) × π × r³ | |

### 2.5 图形变换

```
平移：所有点向同一方向移动相同距离
  (x, y) → (x + dx, y + dy)
  例：向右移 3，向上移 2 → (x+3, y+2)

缩放：所有点相对于某个中心放大或缩小
  (x, y) → (kx, ky)
  k > 1 放大，k < 1 缩小
  例：放大 2 倍 → (2x, 2y)

旋转：所有点绕某个中心转动一定角度
  绕原点旋转 θ 度：
  x' = x × cos(θ) - y × sin(θ)
  y' = x × sin(θ) + y × cos(θ)

翻转（镜像）：
  水平翻转：(x, y) → (-x, y)
  垂直翻转：(x, y) → (x, -y)
```

> 这些变换在 AI 图像增强中天天用到！训练 AI 识别猫时，会把猫的图片旋转、翻转、缩放，让 AI 学会从各个角度认猫。

## 3 基础用法

### 用 Python 计算几何

```python
import math  # 导入数学模块

# === 两点间距离 ===
x1, y1 = 1, 2   # 点 A 的坐标
x2, y2 = 4, 6   # 点 B 的坐标
distance = math.sqrt((x2 - x1)**2 + (y2 - y1)**2)  # 距离公式
print(f"A({x1},{y1}) 到 B({x2},{y2}) 的距离 = {distance}")  # → 5.0

# === 面积计算 ===
# 三角形面积
base = 6    # 底
height = 4  # 高
area_triangle = 0.5 * base * height  # ½ × 底 × 高
print(f"三角形面积 = {area_triangle}")  # → 12.0

# 圆面积
radius = 5  # 半径
area_circle = math.pi * radius ** 2  # π × r²
print(f"圆面积 = {area_circle:.2f}")  # → 78.54

# === 图形变换 ===
# 点的缩放
x, y = 3, 4
scale = 2  # 放大 2 倍
x_new, y_new = x * scale, y * scale
print(f"缩放后：({x_new}, {y_new})")  # → (6, 8)

# 点的旋转（绕原点旋转 90 度）
import math
angle = math.radians(90)  # 角度转弧度
x, y = 3, 4
x_rot = x * math.cos(angle) - y * math.sin(angle)  # 旋转公式
y_rot = x * math.sin(angle) + y * math.cos(angle)
print(f"旋转 90° 后：({x_rot:.1f}, {y_rot:.1f})")  # → (-4.0, 3.0)
```

## 5 新手常见误区

### 误区 1："面积就是长乘宽"

不是的。只有矩形才是长×宽：

```python
# ❌ 错误：三角形也用长×宽
area = 6 * 4  # 这不是三角形面积！

# ✅ 正确：三角形面积 = ½ × 底 × 高
area = 0.5 * 6 * 4  # → 12
```

### 误区 2："角度和弧度是一回事"

不是的。Python 的 math 库用弧度，不是角度：

```python
# ❌ 错误：直接把角度传入 sin/cos
math.sin(90)  # 这不是 sin(90°)！这是 sin(90弧度)

# ✅ 正确：先转弧度
math.sin(math.radians(90))  # → 1.0（sin 90° = 1）
```

### 误区 3："距离就是 x 的差加 y 的差"

距离要用勾股定理，不是简单相加：

```python
# ❌ 错误
distance = abs(x2 - x1) + abs(y2 - y1)  # 这是曼哈顿距离，不是欧氏距离

# ✅ 正确：欧氏距离
distance = math.sqrt((x2-x1)**2 + (y2-y1)**2)
```


### 练习 2：计算面积

一个圆形花坛的半径是 3 米，求它的面积。

<details>
<summary>点击查看答案</summary>

```python
import math
radius = 3  # 半径 3 米
area = math.pi * radius ** 2  # π × r²
print(f"花坛面积 = {area:.2f} 平方米")  # → 28.27 平方米
```

</details>

### 练习 3（挑战）：图形变换

一个点的坐标是 (5, 12)，先向右平移 3 个单位，再放大 2 倍，最终坐标是多少？

<details>
<summary>点击查看答案</summary>

```python
x, y = 5, 12

# 第一步：向右平移 3
x = x + 3  # → 8
y = y      # → 12（y 不变）

# 第二步：放大 2 倍
x = x * 2  # → 16
y = y * 2  # → 24

print(f"最终坐标：({x}, {y})")  # → (16, 24)
```

</details>
