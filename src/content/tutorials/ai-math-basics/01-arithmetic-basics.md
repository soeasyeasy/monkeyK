## 2 核心原理

### 2.1 整数与运算

整数就是没有小数部分的数：..., -3, -2, -1, 0, 1, 2, 3, ...

四种基本运算：

```
加法：3 + 5 = 8         // 两个数合并
减法：8 - 3 = 5         // 从总数中去掉
乘法：3 × 4 = 12        // 重复加法（3+3+3+3）
除法：12 ÷ 4 = 3        // 平均分配
```

### 2.2 运算律（超重要！）

运算律在 AI 的矩阵运算中无处不在：

```
加法交换律：a + b = b + a
  例：3 + 5 = 5 + 3 = 8

加法结合律：(a + b) + c = a + (b + c)
  例：(3 + 5) + 2 = 3 + (5 + 2) = 10

乘法交换律：a × b = b × a
  例：3 × 4 = 4 × 3 = 12

乘法分配律：a × (b + c) = a × b + a × c
  例：2 × (3 + 4) = 2×3 + 2×4 = 6 + 8 = 14
```

> 打个比方：乘法分配律就像"发传单"——2 要分别发给括号里的 3 和 4，不能漏掉任何一个。

### 2.3 小数

小数是整数之间的"细分"：

```
0.5 = 一半 = 1/2
0.25 = 四分之一 = 1/4
0.1 = 十分之一 = 1/10
0.001 = 千分之一 = 1/1000
```

在 AI 中，模型的权重几乎都是小数：

```python
# AI 模型中的权重（都是小数）
weight = 0.0234    # 某个神经元连接的权重
bias = -0.0012     # 偏置值
learning_rate = 0.001  # 学习率
```

### 2.4 分数

分数表示"部分与整体"的关系：

```
  1    ← 分子（取了几份）
 ───
  4    ← 分母（总共分了几份）

读作：四分之一
```

分数的基本运算：

```
同分母加法：1/4 + 2/4 = 3/4     （分母不变，分子相加）

异分母加法：1/3 + 1/4
  = 4/12 + 3/12                  （先通分）
  = 7/12

分数乘法：2/3 × 3/4 = 6/12 = 1/2  （分子乘分子，分母乘分母）

分数除法：2/3 ÷ 4/5 = 2/3 × 5/4 = 10/12 = 5/6  （除以一个数 = 乘以它的倒数）
```

### 2.5 运算优先级

```
优先级从高到低：
1. 括号 ()
2. 乘方 ^
3. 乘法 × 、除法 ÷
4. 加法 + 、减法 -

例：2 + 3 × 4 = 2 + 12 = 14    （先乘后加）
例：(2 + 3) × 4 = 5 × 4 = 20   （括号优先）
```

## 3 基础用法

### 用 Python 验证算术

```python
# === 基本运算 ===
print(3 + 5)      # 加法 → 8
print(10 - 4)     # 减法 → 6
print(3 * 4)      # 乘法 → 12
print(12 / 4)     # 除法 → 3.0（注意：Python 3 中 / 返回浮点数）
print(12 // 4)    # 整除 → 3（只取整数部分）
print(10 % 3)     # 取余 → 1（10 除以 3 余 1）
print(2 ** 3)     # 乘方 → 8（2 的 3 次方）

# === 小数运算 ===
print(0.1 + 0.2)  # → 0.30000000000000004（浮点精度问题！）
# ✅ 正确做法：用 round() 控制精度
print(round(0.1 + 0.2, 1))  # → 0.3

# === 分数运算 ===
from fractions import Fraction  # 导入分数模块
a = Fraction(1, 3)  # 创建分数 1/3
b = Fraction(1, 4)  # 创建分数 1/4
print(a + b)        # → 7/12（自动通分计算）
print(a * b)        # → 1/12
```

> ⚠️ 注意：`0.1 + 0.2` 在计算机中不等于 `0.3`，这是浮点精度问题。在 AI 中很常见，后面会详细讲。

## 5 新手常见误区

### 误区 1："0.1 + 0.2 应该等于 0.3"

**错！** 计算机用二进制存储小数，0.1 和 0.2 无法精确表示：

```python
# ❌ 错误认知
print(0.1 + 0.2 == 0.3)  # → False！

# ✅ 正确做法：比较时允许误差
print(abs(0.1 + 0.2 - 0.3) < 1e-10)  # → True
```

### 误区 2："除法结果一定是整数"

不是的。在 Python 3 中：

```python
# ❌ 错误认知
print(7 / 2)  # → 3.5（不是 3！）

# ✅ 要取整数部分用 //
print(7 // 2)  # → 3
```

### 误区 3："负数不能做运算"

负数完全可以参与运算：

```python
print(-3 + 5)   # → 2
print(-3 * -2)  # → 6（负负得正）
print(-7 / 2)   # → -3.5
```

### 误区 4："先算的就一定写在左边"

运算优先级决定计算顺序，不是位置：

```python
# 2 + 3 × 4 应该先算 3×4=12，再算 2+12=14
print(2 + 3 * 4)  # → 14

# 如果想先算加法，必须加括号
print((2 + 3) * 4)  # → 20
```

## 6 动手练习

### 练习 1：基础运算

计算以下表达式的值：
1. 15 + 27 × 3
2. (15 + 27) × 3
3. 100 ÷ 4 - 10

```python
# 3. 先除后减

```

</details>

### 练习 2：分数运算

用 Python 的 Fraction 模块计算：
1. 1/2 + 1/3
2. 2/5 × 3/4
3. 3/4 ÷ 1/2

<details>
<summary>点击查看答案</summary>

```python
from fractions import Fraction

# 1. 异分母加法
print(Fraction(1, 2) + Fraction(1, 3))  # → 5/6

# 2. 分数乘法
print(Fraction(2, 5) * Fraction(3, 4))  # → 3/10

# 3. 分数除法（除以 1/2 = 乘以 2/1）
print(Fraction(3, 4) / Fraction(1, 2))  # → 3/2
```

</details>

### 练习 3（挑战）：验证运算律

用 Python 验证乘法分配律 a × (b + c) = a × b + a × c，其中 a=7, b=3, c=5。

<details>
<summary>点击查看答案</summary>

```python
a, b, c = 7, 3, 5

# 左边：a × (b + c)
left = a * (b + c)
print(f"左边 = {a} × ({b} + {c}) = {left}")  # → 56

# 右边：a × b + a × c
right = a * b + a * c
print(f"右边 = {a}×{b} + {a}×{c} = {right}")  # → 56

# 验证
print(f"左边 == 右边：{left == right}")  # → True ✅
```

</details>
