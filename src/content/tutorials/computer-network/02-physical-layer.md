# 第2章：物理层基础

## 本章导读

在学这一章之前，你可能会有这些疑问：

- 物理层到底传输什么？是数据还是信号？
- 网线和光纤有什么区别？为什么有的快有的慢？
- 数据是怎么变成电信号或光信号的？
- 为什么网络会有带宽限制？

这一章就是为了解答这些问题。我们会先搞清楚**物理层的基本功能**，再学习**传输介质的特性**，最后理解**数据编码的原理**。

---

## 2.1 为什么需要物理层？

### 痛点分析

如果没有物理层：

- 数据只能在计算机内部处理，无法传输到其他地方
- 就像**有了信件，但没有邮路和交通工具**，信永远送不出去
- 不同设备之间无法建立物理连接

### 解决方案

物理层负责**在传输介质上透明地传输比特流**（0 和 1）。

打个比方：

> 物理层就像**公路本身**，不管车上装的是什么货物（数据），只负责让车辆（比特）能从 A 点开到 B 点。

### 物理层的核心任务

| 任务 | 说明 | 生活例子 |
|------|------|----------|
| 比特传输 | 传输 0 和 1 的电信号/光信号 | 公路上跑的车 |
| 介质定义 | 规定网线、光纤的规格 | 公路的宽度和材质 |
| 信号编码 | 把 0/1 转换成电信号 | 车辆的不同颜色代表不同货物 |
| 同步控制 | 确保收发双方时钟一致 | 收发双方约定速度 |

---

## 2.2 传输介质

### 有线介质

#### 双绞线

**结构**：两根绝缘铜线绞合在一起

**为什么绞合**：减少电磁干扰（EMI）

**分类**：
- **UTP（非屏蔽双绞线）**：家用、办公室常用
- **STP（屏蔽双绞线）**：工业环境，抗干扰强

**常见类型**：

| 类型 | 带宽 | 最大传输距离 | 应用场景 |
|------|------|--------------|----------|
| Cat5 | 100 Mbps | 100 米 | 百兆网络 |
| Cat5e | 1 Gbps | 100 米 | 千兆网络 |
| Cat6 | 10 Gbps | 55 米 | 万兆网络 |
| Cat6a | 10 Gbps | 100 米 | 万兆网络 |

**生活类比**：像**两根缠绕的电话线**，绞合就像两个人手拉手走路，互相保护不被外界干扰。

#### 同轴电缆

**结构**：中心铜导体 + 绝缘层 + 屏蔽层 + 外皮

**特点**：抗干扰能力强，但成本高、安装复杂

**应用**：有线电视、早期以太网

**生活类比**：像**水管**，中间是水流（信号），外面是保护层。

#### 光纤

**结构**：玻璃或塑料纤维，利用全反射原理传输光信号

**分类**：
- **单模光纤**：纤芯细（8-10 微米），传输距离远（几十公里）
- **多模光纤**：纤芯粗（50-62.5 微米），传输距离近（几百米）

**优势**：
- 带宽极高（可达 Tbps 级别）
- 传输距离远
- 不受电磁干扰
- 安全性高（难以窃听）

**生活类比**：像**镜子迷宫**，光在光纤内壁不断反射前进，不会漏出去。

### 无线介质

#### 无线电波

**频率范围**：3 kHz - 300 GHz

**应用**：WiFi、蓝牙、4G/5G、广播

**特点**：
- 无需物理连接
- 易受干扰
- 传输距离有限

#### 微波

**频率范围**：300 MHz - 300 GHz

**应用**：卫星通信、雷达

**特点**：
- 直线传播
- 需要中继站
- 受天气影响

#### 红外线

**应用**：遥控器、短距离通信

**特点**：
- 不能穿透障碍物
- 传输距离短
- 安全性高

## 2.3 数据编码方式

### 为什么需要编码？

计算机内部用 0 和 1 表示数据，但物理介质传输的是电信号、光信号或电磁波。编码就是**把 0/1 转换成适合传输的信号**。

打个比方：

> 编码就像**翻译**，把计算机的语言（0/1）翻译成物理介质能理解的语言（电信号/光信号）。

### 数字数据编码为数字信号

#### 不归零编码（NRZ）

**原理**：
- 高电平 = 1
- 低电平 = 0

**缺点**：
- 无法区分时钟信号
- 长串 0 或 1 时难以同步

**生活类比**：像**开关灯**，亮是 1，灭是 0，但如果一直亮或一直灭，你不知道什么时候该看。

#### 曼彻斯特编码

**原理**：
- 每个比特中间都有跳变
- 从高到低 = 1
- 从低到高 = 0

**优势**：
- 自带时钟同步
- 易于提取定时信息

**应用**：以太网（10 Mbps）

**生活类比**：像**心跳**，每次跳动都代表一个比特，不会漏掉。

#### 差分曼彻斯特编码

**原理**：
- 比特中间有跳变（仅用于同步）
- 比特开始是否有跳变表示 0 或 1

**应用**：令牌环网络

### 数字数据编码为模拟信号

#### 调制技术

**调幅（AM）**：改变信号幅度

**调频（FM）**：改变信号频率

**调相（PM）**：改变信号相位

**生活类比**：
- AM 像**调节音量**，声音大小代表信息
- FM 像**调节音调**，音调高低代表信息
- PM 像**调节节奏**，节奏快慢代表信息

### 模拟数据编码为数字信号

#### 脉冲编码调制（PCM）

**步骤**：
1. **采样**：按固定频率采集模拟信号的值
2. **量化**：把采样值近似为离散值
3. **编码**：把量化值转换为二进制

**采样定理**：采样频率 >= 2 × 最高频率（奈奎斯特定理）

**生活类比**：像**拍照**，采样是按下快门，量化是选择分辨率，编码是保存为数字照片。

## 2.4 数据传输方式

### 按传输方向分类

#### 单工通信

**特点**：数据只能单向传输

**例子**：电视广播、键盘

**生活类比**：像**单行道**，车只能往一个方向开。

#### 半双工通信

**特点**：数据可以双向传输，但不能同时

**例子**：对讲机

**生活类比**：像**独木桥**，一次只能过一边，过完才能换方向。

#### 全双工通信

**特点**：数据可以同时双向传输

**例子**：电话、网络通信

**生活类比**：像**双向车道**，车可以同时往两个方向开。

### 按传输方式分类

#### 串行传输

**特点**：数据一位一位依次传输

**优势**：成本低、适合长距离

**应用**：USB、SATA、网络通信

**生活类比**：像**排队过安检**，一个人一个人过。

#### 并行传输

**特点**：数据多位同时传输

**优势**：速度快

**缺点**：成本高、不适合长距离、信号干扰

**应用**：早期打印机接口、内存总线

**生活类比**：像**多车道收费站**，多辆车同时通过。

## 2.5 信道与带宽

### 什么是信道？

**定义**：信号传输的通道

**分类**：
- **模拟信道**：传输模拟信号
- **数字信道**：传输数字信号

### 带宽

**定义**：信道能够传输的最高频率与最低频率之差

**单位**：Hz（模拟带宽）或 bps（数字带宽）

**生活类比**：像**公路的宽度**，带宽越宽，能同时跑的车越多，传输的数据越多。

### 香农定理

**公式**：C = W × log₂(1 + S/N)

- C：信道容量（最大传输速率）
- W：带宽
- S/N：信噪比

**意义**：给出了信道传输速率的理论上限

**生活类比**：像**公路的通行能力**，路越宽（带宽大）、路况越好（信噪比高），能跑的车越多。

### 奈奎斯特定理

**公式**：C = 2W × log₂(V)

- C：信道容量
- W：带宽
- V：离散电平数

**意义**：无噪声信道的最大传输速率

## 2.6 核心知识点总结

| 知识点 | 说明 |
|--------|------|
| 物理层功能 | 在传输介质上透明传输比特流 |
| 双绞线 | 两根铜线绞合，减少干扰 |
| 光纤 | 利用全反射传输光信号，带宽高 |
| 曼彻斯特编码 | 比特中间跳变，自带同步 |
| 调制技术 | AM、FM、PM |
| PCM | 采样、量化、编码 |
| 单工/半双工/全双工 | 单向/交替双向/同时双向 |
| 带宽 | 信道传输能力的度量 |

## 2.7 新手常见误区

### 误区 1："光纤传输的是电信号"

**错！** 光纤传输的是光信号，不是电信号。光纤通过全反射原理传输光，需要光电转换器将电信号转为光信号。

### 误区 2："带宽越大，网速越快"

不准确。带宽是信道的理论最大传输能力，实际网速还受延迟、丢包、拥塞等因素影响。就像公路宽不代表车跑得快，还可能堵车。

### 误区 3："串行传输比并行传输慢"

不一定。虽然并行传输一次传多位，但串行传输可以提高时钟频率。现代技术中，串行传输（如 USB 3.0、SATA）速度往往超过并行传输。

### 误区 4："双绞线越长越好"

不对。双绞线有最大传输距离限制（通常 100 米），超过距离信号会衰减，需要使用中继器或交换机。

### 练习 3（挑战）：带宽计算

假设一个信道的带宽是 4 kHz，信噪比是 30 dB，请计算该信道的最大传输速率（香农定理）。

<details>
<summary>点击查看答案</summary>

```
已知：
- W = 4 kHz = 4000 Hz
- S/N = 30 dB = 10^(30/10) = 1000

香农定理：C = W × log₂(1 + S/N)
C = 4000 × log₂(1 + 1000)
C = 4000 × log₂(1001)
C ≈ 4000 × 9.97
C ≈ 39880 bps ≈ 39.88 kbps

所以该信道的最大传输速率约为 39.88 kbps。
```

</details>
