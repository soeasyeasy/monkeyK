# 第10章：无线网络与移动网络

## 本章导读

在学这一章之前，你可能会有这些疑问：

- WiFi 是怎么传输数据的？和有线网络有什么区别？
- 蓝牙和 WiFi 有什么不同？各自适合什么场景？
- 4G 和 5G 有什么区别？5G 到底快在哪里？
- 手机从 WiFi 切换到 4G 时，为什么不会断网？

这一章就是为了解答这些问题。我们会先搞清楚**无线通信的基本原理**，再对比**各种无线技术的特点**，最后了解**移动通信的发展历程**。

---

## 1 为什么需要无线网络？

### 痛点分析

有线网络的局限：

- 布线成本高，尤其在古建筑、大范围区域
- 移动设备无法使用有线网络
- 临时网络需求难以满足
- 就像**电话必须有电话线**，不能边走边打

### 解决方案

无线网络使用**电磁波**代替物理线缆传输数据。

打个比方：

> 无线网络就像**对讲机**，不需要线缆，通过无线电波就能通信，但距离和干扰是主要挑战。

## 2 无线通信基本原理

### 电磁波频谱

| 类型 | 频率范围 | 应用 |
|------|----------|------|
| 无线电波 | 3 kHz - 300 GHz | 广播、WiFi、移动通信 |
| 微波 | 300 MHz - 300 GHz | 卫星通信、雷达 |
| 红外线 | 300 GHz - 430 THz | 遥控器 |
| 可见光 | 430 THz - 750 THz | Li-Fi（可见光通信） |

### 无线传输的挑战

| 挑战 | 说明 | 解决方案 |
|------|------|----------|
| 信号衰减 | 距离越远信号越弱 | 增加基站/中继器 |
| 多径效应 | 信号经反射后产生多条路径 | OFDM、MIMO |
| 干扰 | 其他设备或网络干扰 | 频段划分、跳频 |
| 安全性 | 无线信号容易被截获 | 加密协议（WPA3） |
| 带宽有限 | 频谱资源有限 | 频谱复用、压缩技术 |

## 3 WiFi 技术

### WiFi 标准

**标准**：IEEE 802.11

| 标准 | 发布年份 | 频段 | 最大速率 | 覆盖范围 |
|------|----------|------|----------|----------|
| 802.11b | 1999 | 2.4 GHz | 11 Mbps | 约 35 米 |
| 802.11g | 2003 | 2.4 GHz | 54 Mbps | 约 38 米 |
| 802.11n (WiFi 4) | 2009 | 2.4/5 GHz | 600 Mbps | 约 70 米 |
| 802.11ac (WiFi 5) | 2013 | 5 GHz | 6.9 Gbps | 约 50 米 |
| 802.11ax (WiFi 6) | 2019 | 2.4/5/6 GHz | 9.6 Gbps | 约 50 米 |
| 802.11be (WiFi 7) | 2024 | 2.4/5/6 GHz | 46 Gbps | 约 50 米 |

### WiFi 工作模式

#### 基础设施模式（Infrastructure）

```
设备 A → 无线接入点（AP/路由器） → 设备 B
```

最常见的模式，所有设备通过路由器通信。

#### 自组织模式（Ad Hoc）

```
设备 A ←→ 设备 B
```

设备之间直接通信，不需要路由器。

### WiFi 安全协议

| 协议 | 加密方式 | 安全性 |
|------|----------|--------|
| WEP | RC4 | 不安全（已破解） |
| WPA | TKIP | 一般（不推荐） |
| WPA2 | AES-CCMP | 安全（推荐） |
| WPA3 | AES-GCMP | 最安全（最新） |

### 2.4 GHz vs 5 GHz

| 对比项 | 2.4 GHz | 5 GHz |
|--------|---------|-------|
| 覆盖范围 | 广 | 窄 |
| 穿透能力 | 强 | 弱 |
| 可用信道 | 3 个（不重叠） | 24 个（不重叠） |
| 干扰 | 多（微波炉、蓝牙） | 少 |
| 速率 | 较低 | 较高 |

## 4 蓝牙技术

### 蓝牙标准

| 版本 | 发布年份 | 速率 | 距离 | 特点 |
|------|----------|------|------|------|
| 蓝牙 4.0 | 2010 | 25 Mbps | 60 米 | 低功耗（BLE） |
| 蓝牙 4.2 | 2014 | 25 Mbps | 150 米 | 隐私增强 |
| 蓝牙 5.0 | 2016 | 50 Mbps | 400 米 | 2 倍速率、4 倍范围 |
| 蓝牙 5.3 | 2020 | 50 Mbps | 400 米 | 低功耗音频 |
| 蓝牙 5.4 | 2023 | 50 Mbps | 400 米 | 电子货架标签 |

### 蓝牙 vs WiFi

| 对比项 | 蓝牙 | WiFi |
|--------|------|------|
| 速率 | 低（50 Mbps） | 高（9.6 Gbps） |
| 距离 | 短（10-400 米） | 中（50-100 米） |
| 功耗 | 低 | 高 |
| 复杂度 | 简单 | 复杂 |
| 应用场景 | 耳机、手环、传感器 | 上网、视频、文件传输 |

### 蓝牙应用场景

- 无线耳机/音箱
- 智能手表/手环
- 无线键鼠
- 车载系统
- IoT 传感器

## 5 移动通信

### 移动通信发展历程

| 代际 | 年代 | 技术 | 速率 | 主要应用 |
|------|------|------|------|----------|
| 1G | 1980s | 模拟通信 | 2.4 kbps | 语音通话 |
| 2G | 1990s | GSM/CDMA | 64 kbps | 语音+短信 |
| 3G | 2000s | WCDMA/CDMA2000 | 2 Mbps | 移动互联网 |
| 4G | 2010s | LTE/LTE-A | 100 Mbps-1 Gbps | 高清视频、移动支付 |
| 5G | 2020s | NR（New Radio） | 10-20 Gbps | 物联网、自动驾驶 |

### 4G LTE 核心技术

| 技术 | 说明 |
|------|------|
| OFDM | 正交频分复用，抗多径干扰 |
| MIMO | 多输入多输出，提高吞吐量 |
| 载波聚合 | 多个频段合并使用 |
| QAM | 高阶调制（64QAM/256QAM） |

### 5G 三大应用场景

| 场景 | 特点 | 应用 |
|------|------|------|
| eMBB（增强移动宽带） | 高速率 | 4K/8K 视频、VR/AR |
| mMTC（海量机器通信） | 大连接 | 物联网、智慧城市 |
| uRLLC（低时延高可靠） | 低延迟 | 自动驾驶、远程医疗 |

### 4G vs 5G 对比

| 对比项 | 4G | 5G |
|--------|-----|-----|
| 峰值速率 | 1 Gbps | 20 Gbps |
| 延迟 | 10-50 ms | 1-10 ms |
| 连接密度 | 10 万/km² | 100 万/km² |
| 频段 | Sub-6 GHz | Sub-6 GHz + 毫米波 |
| 核心技术 | OFDM、MIMO | 大规模 MIMO、波束赋形 |
| 网络架构 | 全 IP | 网络切片、边缘计算 |

## 6 核心知识点总结

| 知识点 | 说明 |
|--------|------|
| WiFi | IEEE 802.11，2.4/5/6 GHz，短距离高速 |
| 蓝牙 | 低功耗短距离，适合 IoT 和音频 |
| 1G-5G | 模拟→数字→移动宽带→高速低延迟 |
| 5G 三大场景 | eMBB、mMTC、uRLLC |
| OFDM | 正交频分复用，抗多径 |
| MIMO | 多天线技术，提高吞吐量 |

## 7 新手常见误区

### 误区 1："5G 只是比 4G 快"

**错！** 5G 不仅是速度快，还有低延迟（1ms）和大连接（百万级设备/km²）。这些特性使能自动驾驶、远程医疗等全新应用。

### 误区 2："WiFi 6 比 5G 快"

不准确。WiFi 6 理论速率 9.6 Gbps，5G 理论速率 20 Gbps。但实际速率取决于环境、设备、距离等因素。WiFi 在室内短距离更有优势，5G 在广域覆盖更强。

### 误区 3："蓝牙 5.0 可以替代 WiFi"

不对。蓝牙 5.0 速率只有 50 Mbps，远低于 WiFi。蓝牙适合低功耗短距离场景（耳机、传感器），WiFi 适合高速数据传输。

### 误区 4："5G 毫米波对人体有害"

没有科学依据。5G 使用的电磁波属于非电离辐射，能量不足以破坏分子结构。国际卫生组织（WHO）认为在安全限值内的 5G 辐射不会对人体造成伤害。

```
- 推荐 2.4 GHz 频段
```

### 练习 2：移动通信对比

请对比 4G 和 5G 在速率、延迟、连接密度方面的差异，并说明 5G 的低延迟特性适合哪些应用。

<details>
<summary>点击查看答案</summary>

```
对比：
- 速率：4G 峰值 1 Gbps，5G 峰值 20 Gbps（20 倍）

- 连接密度：4G 约 10 万/km²，5G 约 100 万/km²（10 倍）

5G 低延迟应用：
- 自动驾驶：需要毫秒级反应时间
- 远程手术：医生远程操控手术机器人
```

### 练习 3（挑战）：无线技术选型

假设你需要为一个智能工厂设计无线通信方案，有以下需求：
1. 生产线上的传感器（温度、湿度）需要实时上报数据
2. 工人佩戴的 AR 眼镜需要传输高清视频
3. 仓库的 AGV 小车需要精确控制

请为每个场景选择合适的无线技术，并说明理由。

<details>
<summary>点击查看答案</summary>

```
1. 传感器数据上报：
   - 选择：蓝牙 BLE 或 LoRa
   - 理由：传感器数据量小，需要低功耗，BLE 适合短距离，LoRa 适合远距离
   - 数据量：几 KB/s，不需要高带宽

2. AR 眼镜高清视频：
   - 选择：WiFi 6 或 5G
   - 理由：高清视频需要高带宽（几十 Mbps），WiFi 6 和 5G 都能满足
   - 如果在室内固定区域，WiFi 6 更合适；如果需要移动覆盖，5G 更好

3. AGV 小车精确控制：
   - 选择：5G（uRLLC 场景）
   - 理由：需要低延迟（<10ms）和高可靠性
   - 5G uRLLC 可以提供毫秒级延迟和 99.999% 可靠性
```

</details>
