# 第一章：Linux 简介与环境搭建

## 本章导读

在学这一章之前，你可能会有这些疑问：

- Linux 到底是什么？和 Windows 有什么区别？
- 为什么服务器都在用 Linux，但我平时用不到？
- Linux 发行版那么多，我该选哪个？
- 我又不想重装系统，怎么体验 Linux？

这一章就是为了解答这些问题。我们会先搞清楚 **Linux 是什么、为什么重要**，再帮你选一个合适的发行版，最后用虚拟机或 WSL 搭建一个可以动手实践的环境。

---

## 1.1 为什么需要 Linux？

### 痛点分析

想象一下这样的场景：

你想搭建一个网站，结果发现：
- Windows 服务器要花钱买授权
- 很多开源工具在 Windows 上装不了
- 网上教程全是 Linux 命令，你看不懂

更糟糕的是，你终于把环境配好了，结果换个电脑又要重来一遍。

这就是不用 Linux 时的日常：**工具受限、教程看不懂、环境难复现**。

### 解决方案

Linux 的出现就是为了解决这些问题。它是一个**免费、开源、强大**的操作系统：

- 完全免费，不用花钱买授权
- 几乎所有开发工具都原生支持
- 网上 90% 的服务器教程都是基于 Linux

打个比方：

> Windows 像是一辆自动挡轿车——开箱即用，但你想改装发动机？门都没有。
>
> Linux 像是一辆手动挡越野车——刚开始学可能有点难，但一旦学会了，你能去任何地方，还能自己改装。

### 前后对比

```
不用 Linux：
- 想学 Docker？Windows 上跑不起来
- 想部署网站？服务器是 Linux，本地是 Windows，环境不一致
- 想看教程？"执行以下命令"，结果全是 Linux 命令

用 Linux：
- Docker、Node.js、Python、Git... 所有工具一键安装
- 本地和服务器环境一致，代码到哪都能跑
- 教程里的命令直接复制粘贴就能用
```

> **一句话总结**：Linux 让你告别"在我电脑上是好的"，成为真正的开发者。

## 1.2 Linux 是什么？

### 概念解释

Linux 是一个**开源的操作系统内核**，由 Linus Torvalds 在 1991 年创建。我们平时说的"Linux"通常指的是 **Linux 发行版**（比如 Ubuntu、CentOS），它们包含了 Linux 内核 + 各种软件 + 包管理器。

打个比方：

> Linux 内核就像汽车的发动机——它是核心部件，但光有发动机不能上路。
>
> Linux 发行版就像整车——Ubuntu、CentOS 这些发行版把发动机、轮胎、方向盘都配好了，拿来就能用。

### Linux 的组成

| 组成部分 | 作用 | 类比 |
| --- | --- | --- |
| 内核（Kernel） | 管理硬件、进程、内存 | 汽车发动机 |
| Shell | 命令行解释器，接收用户命令 | 方向盘和踏板 |
| 文件系统 | 组织和管理文件 | 后备箱和储物空间 |
| 应用程序 | 各种工具和软件 | 空调、音响等配件 |

### Linux vs Windows vs macOS

| 特性 | Linux | Windows | macOS |
| --- | --- | --- | --- |
| 价格 | 免费 | 付费 | 付费（绑定硬件） |
| 开源 | 完全开源 | 闭源 | 部分开源 |
| 命令行 | 强大，原生支持 | PowerShell，较弱 | Terminal，较好 |
| 服务器市场占有率 | 90%+ | 5%左右 | 几乎为 0 |
| 学习曲线 | 较陡 | 平缓 | 中等 |
| 适合场景 | 服务器、开发、嵌入式 | 办公、游戏 | 设计、开发 |

## 1.3 Linux 发行版选择

### 常见发行版

Linux 发行版有很多，新手最容易选晕。我们来梳理一下主流的发行版：

| 发行版 | 特点 | 适合人群 | 包管理器 |
| --- | --- | --- | --- |
| Ubuntu | 最流行，教程最多，社区活跃 | 新手首选 | apt |
| CentOS | 企业级稳定，服务器常用 | 运维人员 | yum/dnf |
| Debian | 稳定保守，Ubuntu 的爸爸 | 追求稳定的服务器 | apt |
| Fedora | 技术前沿，更新快 | 想尝试新特性的开发者 | dnf |
| Arch Linux | 高度自定义，滚动更新 | 高级玩家 | pacman |
| Manjaro | Arch 的易用版 | 想用 Arch 又怕麻烦的人 | pacman |

### 新手推荐

如果你是**纯新手**，我推荐：

1. **Ubuntu Desktop**（首选）：教程最多，遇到问题容易搜到答案
2. **Ubuntu Server**（想挑战一下）：没有图形界面，纯命令行，更接近真实服务器环境

> **一句话建议**：别纠结，就选 Ubuntu。等你用熟了，自然会知道下一个该用什么。

## 1.4 环境搭建

### 方案对比

你有三种方式体验 Linux，不需要重装系统：

| 方案 | 优点 | 缺点 | 适合场景 |
| --- | --- | --- | --- |
| 虚拟机（VirtualBox/VMware） | 完全隔离，安全 | 占用资源多，启动慢 | 想完整体验 Linux |
| WSL（Windows Subsystem for Linux） | 轻量，集成好 | 部分功能受限 | Windows 用户日常开发 |
| 云服务器 | 真实环境，随时可访问 | 要花钱 | 想部署真实项目 |

### 方案一：使用 VirtualBox 安装 Ubuntu

#### 步骤 1：下载 VirtualBox

去 [VirtualBox 官网](https://www.virtualbox.org/) 下载安装包，一路下一步安装即可。

#### 步骤 2：下载 Ubuntu 镜像

去 [Ubuntu 官网](https://ubuntu.com/download/desktop) 下载 ISO 镜像文件。推荐下载 **LTS（长期支持）版本**，比如 22.04 LTS。

#### 步骤 3：创建虚拟机

```bash
# ❶ 打开 VirtualBox，点击"新建"
# ❷ 名称填"Ubuntu"，类型选"Linux"，版本选"Ubuntu (64-bit)"
# ❸ 内存分配 2GB 以上（推荐 4GB）
# ❹ 创建虚拟硬盘，选择"现在创建虚拟硬盘"
# ❺ 硬盘类型选"VDI"
# ❻ 分配方式选"动态分配"
# ❼ 硬盘大小至少 20GB（推荐 40GB）
```

#### 步骤 4：安装 Ubuntu

```bash
# ❶ 选中刚创建的虚拟机，点击"启动"
# ❷ 选择刚才下载的 Ubuntu ISO 镜像文件
# ❸ 进入安装界面，选择"Install Ubuntu"
# ❹ 选择语言为"中文（简体）"
# ❺ 选择"正常安装"，勾选"安装时下载更新"
# ❻ 选择"清除整个磁盘并安装"（虚拟机里放心选）
# ❼ 设置时区为"Shanghai"
# ❽ 设置用户名和密码（密码要记住！）
# ❾ 等待安装完成，重启虚拟机
```

#### 步骤 5：验证安装

```bash
# 打开终端（快捷键 Ctrl+Alt+T），输入以下命令

# 查看系统版本
lsb_release -a  # 显示 Ubuntu 版本信息

# 查看内核版本
uname -r  # 显示 Linux 内核版本号

# 查看系统信息
cat /etc/os-release  # 显示操作系统的详细信息

# ✅ 如果以上命令都能正常输出，说明安装成功
```

### 方案二：使用 WSL（推荐 Windows 用户）

WSL 是 Windows 10/11 自带的 Linux 子系统，不用装虚拟机，轻量又方便。

#### 步骤 1：启用 WSL

```powershell
# ❶ 以管理员身份打开 PowerShell
# ❷ 执行以下命令启用 WSL
wsl --install

# ❸ 重启电脑
# ❹ 重启后会自动安装 Ubuntu，设置用户名和密码
```

#### 步骤 2：验证安装

```bash
# 打开 Ubuntu 终端，输入以下命令

# 查看 WSL 版本
wsl --version  # 显示 WSL 的版本信息

# 查看已安装的发行版
wsl --list --verbose  # 列出所有已安装的 Linux 发行版

# 进入 Ubuntu
wsl  # 直接进入默认的 Ubuntu 环境

# ✅ 如果能正常进入 Ubuntu 环境，说明安装成功
```

#### 步骤 3：基础配置

```bash
# 更新软件包列表
sudo apt update  # 从服务器获取最新的软件包信息

# 升级已安装的软件
sudo apt upgrade -y  # 升级所有已安装的软件包，-y 表示自动确认

# 安装常用工具
sudo apt install -y vim git curl wget  # 安装 vim 编辑器、git 版本控制、curl 和 wget 下载工具

# ✅ 配置完成，可以开始使用了
```

如果你想体验真实的服务器环境，可以买一台云服务器。


## 1.5 第一次使用 Linux

### 终端初体验

安装好 Linux 后，打开终端（Terminal），你会看到一个黑色的窗口，闪着光标等你输入命令。

```bash
# 终端提示符通常长这样：
user@hostname:~$

# user 是当前用户名
# hostname 是主机名
# ~ 表示当前目录是家目录
# $ 表示普通用户（如果是 # 表示 root 用户）
```

### 基础命令

```bash
# 查看当前所在目录
pwd  # Print Working Directory，显示当前工作目录的完整路径

# 查看当前目录下的文件
ls  # List，列出当前目录下的文件和文件夹

# 进入某个目录
cd /home  # Change Directory，切换到 /home 目录

# 回到家目录
cd ~  # ~ 代表家目录，等同于 cd /home/用户名

# 清屏
clear  # 清空终端屏幕，让界面更干净

# 查看命令帮助
man ls  # Manual，查看 ls 命令的详细帮助文档
# 按 q 退出帮助文档
```

### sudo 和 root

```bash
# root 是超级管理员，拥有最高权限
# sudo 是"以管理员身份执行命令"

# 普通用户执行管理员命令
sudo apt update  # 需要输入密码才能执行

# 切换到 root 用户
sudo su  # 输入密码后，提示符变成 #

# 退出 root 用户
exit  # 回到普通用户

# ✅ 推荐做法：尽量用 sudo，不要一直用 root
# ❌ 危险做法：直接用 root 用户日常操作，容易误删系统文件
```

## 1.7 新手常见误区

### 误区 1："Linux 就是命令行，没有图形界面"

**错！** Linux 可以有图形界面（GUI），比如 Ubuntu Desktop 就有完整的桌面环境。但服务器通常不装图形界面，因为：
- 图形界面占用资源
- 命令行效率更高
- 远程管理更方便

### 误区 2："Linux 命令大小写都可以"

**错！** Linux 命令**严格区分大小写**：

```bash
ls  # ✅ 正确：列出文件
LS  # ❌ 错误：command not found
Cd  # ❌ 错误：command not found
cd  # ✅ 正确：切换目录
```

### 误区 3："root 用户更安全，因为权限最大"

**错！** 日常使用 root 用户反而**更危险**：
- 一个 `rm -rf /` 就能删掉整个系统
- 病毒或恶意软件会以最高权限运行
- 误操作无法挽回

正确做法：日常用普通用户，需要管理员权限时用 `sudo`。

### 误区 4："WSL 和虚拟机没区别"

**不完全对。** 它们有本质区别：

| 特性 | WSL | 虚拟机 |
| --- | --- | --- |
| 性能 | 接近原生 | 有性能损耗 |
| 资源占用 | 低 | 高 |
| 隔离性 | 较弱 | 完全隔离 |
| 图形界面 | 支持有限 | 完整支持 |
| 适合场景 | 开发、学习 | 完整体验、测试 |

### 误区 5："学 Linux 必须先装双系统"

**不需要！** 双系统有风险（可能丢数据），而且没必要。用虚拟机或 WSL 就能完整学习 Linux，等真的需要了再考虑双系统。

### 练习 3（挑战）：综合练习 - 云服务器连接

**题目**：连接云服务器并完成基础配置。

要求：
1. 使用 SSH 连接云服务器
2. 更新系统软件包
3. 创建一个普通用户
4. 给新用户添加 sudo 权限

<details>
<summary>点击查看答案</summary>

```bash
# ❶ 连接云服务器
ssh root@你的服务器IP

# ❷ 更新系统
sudo apt update
sudo apt upgrade -y

# ❸ 创建新用户（比如叫 newuser）
sudo adduser newuser
# 按提示输入密码和用户信息

# ❹ 给新用户添加 sudo 权限
sudo usermod -aG sudo newuser

# ❺ 验证新用户是否有 sudo 权限
su - newuser  # 切换到新用户
sudo whoami  # 应该输出 root

# ✅ 如果能正常切换到新用户并执行 sudo 命令，说明配置成功
```

</details>
